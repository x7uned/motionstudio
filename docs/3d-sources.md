# Готовые 3D-модели: где брать и как готовить

Решение пользователя 2026-10-21: держать в студии реестр бесплатных источников 3D-моделей и чек-лист подготовки. Основа — справочники скилла vizavi_motion (`references/3d-sources.md`, `references/models-3d.md`), переданные пользователем. Их исследование датировано 16.10.2026 и проверяло документацию сайтов, а не каждый файл. Условия меняются: при скачивании проверяй страницу и лицензию конкретной модели.

Как модель попадает в ролик, описано в [3d-renderer.md](3d-renderer.md): GLB 2.0 или embedded GLTF 2.0 загружается в библиотеку `data/models/`, проект получает свой снимок `models/` с SHA-256. При рендере нет сетевых зависимостей.

## Источники

| Задача | Источник | Что учитывать |
|---|---|---|
| Реалистичные предметы | [Poly Haven Models](https://polyhaven.com/models) | glTF, CC0, без регистрации. Проверь комплект текстур. |
| Стилизованные наборы (low-poly) | [Kenney Assets](https://kenney.nl/assets) | Бери 3D-набор с GLB, CC0. «Continue without donating» скачивает бесплатно. Ближе всего к нашему low-poly стилю. |
| Персонажи и риги | [Quaternius](https://quaternius.com/) | Бесплатные Standard-выпуски, FBX/glTF. Лицензия QAL v1.0 (28.08.2026): готовые ролики можно, распространять сами ассеты и паки нельзя. У части старых выпусков CC0 — смотри лицензию конкретного выпуска. |
| 3D-сканы | [ambientCG](https://ambientcg.com/list?type=3d-model,terrain) | CC0. Проверь формат в ZIP: не каждый объект в GLB. |
| Конкретные устройства | [Sketchfab](https://sketchfab.com/) | Фильтр downloadable/free, glTF/GLB, лицензия модели (часто CC BY — нужна атрибуция). Для скачивания нужен аккаунт пользователя; агент сам не регистрируется. |
| Бесплатное с фильтром формата | [CGTrader](https://www.cgtrader.com/3d-models?free=1) | Проверь реальную нулевую цену и условия. «Free in subscription» не значит свободно. |
| Стилизованные персонажи | [KayKit Adventurers](https://kaylousberg.itch.io/kaykit-adventurers) | Бесплатно 5 моделей FBX/glTF, CC0. Дополнения платные. |
| Технический резерв | [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets) | Лицензия в README каждого ассета, не общая. |

**Poly Pizza** — не использовать как автоматический источник: [условия](https://poly.pizza/docs/tos) ограничивают автоматические загрузки. Ограничения доступа не обходим.

## Подготовка модели перед сценой

1. Открой и отрендери сам файл, а не превью сайта. Проверь меш, UV, текстуры, материалы, риг и анимации, внешние зависимости.
2. Нормализуй единицы, масштаб, оси, положение, origin/pivot. Проверь нормали, толщину, прозрачность, roughness/metalness, color space текстур. Для нормализации есть `model-layout.json` (см. 3d-renderer.md).
3. Тяжёлые меши и текстуры уменьшай с сохранением силуэта. Проверь реальную скорость рендера.
4. Свет и тени под материал: пластик, металл и стекло должны вести себя по-разному. Блик не исправляет неверную форму.
5. Шарниры — относительное вращение части: у ноутбука крышка вращается вокруг оси петли, а не весь корпус.
6. При близком проезде камера не пересекает near-plane, фокус на герое.

## Запись источника

В проекте рядом с моделью: сайт и точная страница, автор и название, формат, лицензия или условия с датой проверки, нужная атрибуция, внесённые изменения. Атрибуция CC BY попадает в `credits.txt` и описание ролика. Право скачать не равно праву распространять сам файл.
