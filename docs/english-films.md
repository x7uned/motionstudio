# Английский выпуск ролика · 2026-10-19

По умолчанию все проекты русские. Английский — явный выбор редактора при создании: «Язык ролика · English». Снимок профиля получает `production.language="en"`. У русских проектов поля нет, поэтому их промпты, кэши ролей, хеши и снимки не меняются. Старые проекты, `tech-story/v1` и готовые планы (`initialPlan`) английский режим не получают: сервер отклоняет такой выбор.

## Что меняется в EN-проекте

- **Роли сценария** (поиск, исследование, рассказ, редактор, извлечение и проверка утверждений, разметка, визуальная концепция) получают в конце промпта языковую директиву `languageDirective(profile)` из `src/lib/quality-contract.ts`. По ней весь произносимый и экранный текст пишется на естественном американском английском «для слуха», а не переводом с русского. Цитаты-доказательства остаются на языке источника. Пояснения для редактора (reason, findings, notes) могут оставаться по-русски. Снимки SKILL.md неизменяемы и не переписываются: директива указывает применять упоминания русского языка к английскому.
- **Motion-режиссёры** (2D, 3D, netcode, illustrated, scene-builder) получают директиву «motion»: все видимые подписи — короткий английский текст из проверенного сценария.
- **Ревью кадров** получает директиву «review»: русский или смешанный текст в кадре — замечание.
- **Темп.** `wordsPerSecond(language,long)`: русский 1,9 / 2,15 слова/с (как раньше), английский 2,8 / 3,0 — это предел. Цель сценариста: 2,3–2,6 слова/с для Shorts, 2,5–2,8 для длинных роликов (голос Dennis читает английский около 3,1 слова/с). Каждая английская сцена при разметке содержит не меньше 11 слов, иначе глава короче 3 с и озвучка не размечается. Длительность — по-прежнему потолок, без растягивания и ускорения.
- **Голос** — выбор редактора: Dennis (`Uk2wBdgJpwqwirqxDggc`), Eleven v4, английская подача `DEFAULT_DELIVERY_EN`. Профиль `DEFAULT_EN_VOICE_PROFILE` можно заменить настройкой `selectedVoiceProfileEn`. Русский выбранный голос и голоса шаблонов на EN не переносятся. `voice-plan.json` получает `language:"en"`. Для v4 `elevenlabs_speech.py` передаёт `language_code` по языку проекта, раньше было зашито `ru`; для multilingual v2 language_code не передаётся, как и прежде. Это по-прежнему один запрос и один непрерывный PCM-мастер.
- **Слова и подписи.** `TOKEN_EN` сохраняет сокращения и притяжательные формы (`don't`, `xtuned's`), знак валюты и числа через дефис (`2,000-byte`) как одно слово подписи; русский `TOKEN` не изменён. Подписи переносят английские служебные слова (a, the, to, of…) вместе со следующим словом. Шрифт Manrope покрывает латиницу. Вшитые строки quality-рендеров (Explainer «BASICS», 3D-оговорка, netcode «HOOK», «server rewinds time», «ms») выбираются по языку.
- **Сверка ASR.** Scribe v2 вызывается с `language_code="eng"`. Сравнение ведётся без учёта регистра и стиля апострофа. `brandCheck` требует, чтобы каждое «xtuned» было услышано как xtuned / X tuned / ex-tuned; иначе отчёт получает статус `changes` и требует прослушивания. Русская сверка (ё→е) не изменена.
- **Заставка @xtuned** берёт EN-вариант (`Want more breakdowns like this? Follow xtuned.`, Follow → Following) из `projectLanguage(profile)` при снимке пака (см. creator-outro.md).
- В слепом сравнении текста критерий называется «Естественность английского на слух».

## Простой английский · 2026-10-22

Правило редактора для обоих аккаунтов: английский текст ролика должен понимать зритель, который знает английский на базовом уровне, с первого прослушивания. Новые EN-проекты получают `production.plainEnglish=1`. Тогда `languageDirective` добавляет к промптам ролей сценария (исследование, рассказ, редактор, разметка, визуальная концепция, перевод `translate-illustrated`) блок `PLAIN_ENGLISH`:

- частые бытовые слова; простое слово вместо книжного (use, get, show вместо utilize, obtain, demonstrate);
- короткие прямые предложения, в основном одна мысль, подлежащее → глагол → дополнение, активный залог, простые времена;
- без идиом, сленга, редких слов, игры слов для носителей, длинных вложенных оборотов и цепочек существительных;
- технический термин, если это тема ролика, остаётся, но сразу объясняется простыми словами; другого жаргона не добавлять;
- просто, но не по-детски: сильная первая фраза, причинный рассказ, точные числа и естественный ритм речи сохраняются.

Motion-режиссёры получают короткую оговорку: экранные слова — простые, знакомые изучающему английский. В режиме агента правило приходит агенту в prompt.md задачи, и он пишет текст по нему. Старые EN-проекты (поля нет), русские промпты и сохранённые шаблоны не меняются байт в байт.

Проверка: `scripts/english.test.ts` (изолированная временная папка с проверкой `store.DATA`), `scripts/test_elevenlabs_en.py`.

## Приёмочный прогон · 2026-10-19

Проект `b2f29a5d` («How DNS finds its next stop», 30 с, 9:16, 2D, фактчекинг выключен) прошёл create → исследование → рассказ → редактор → разметка → визуальная концепция → TTS → Scribe → 2D-постановка → рендер → ревью. Итоговый `video.mp4`: 1080×1920, 720 кадров/24 с при 30 fps, H.264/yuv420p/BT.709, AAC 48 кГц, −16,81 LUFS, −4,46 dBTP. Scribe: WER 0, бренд «xTuned» распознан. Ролик проигран в браузере целиком (720/720 кадров, без пропусков, со звуком). Прослушивание и одобрение остаются за редактором.

Что выяснилось в прогоне и исправлено:
- Голос Dennis читает английский текст около 3,1 слова/с. Сцены по 7–8 слов длились меньше 3 с, и озвучка не размечалась. Поэтому английская разметка требует от сцены не меньше 11 слов, а цель темпа поднята.
- `TOKEN_EN` сохраняет доменные имена и сокращения целыми словами подписи: `example.com`, `.com`, `U.S.`.
- Повтор 2D motion-режиссёра теперь перечисляет пары «сцена/узел» без `reveal` в той же сцене. Это общий контракт `validateDirectedPlan`, он не зависит от языка.
- `brandCheck` считает слитное «xTuned» один раз.

Оставшиеся замечания ревью — ограничения 2D-рендерера, а не языка: у Root hints нет строк списка, ответная стрелка не выделена жёлтым. Предупреждения safe-zone для шапки «BASICS» и счётчика глав совпадают с прежней раскладкой русской шапки «С НУЛЯ».
