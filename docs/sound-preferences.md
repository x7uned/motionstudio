# Звуковые предпочтения @xtuned · 2026-10-18

После прослушивания пользователь оставил три универсальных акцента: `ui-reveal` (появление/изменение элемента), `soft-whoosh` (переход, включая заставку), `ui-highlight` (смысловой акцент и имя). Использовать чаще на заметных изменениях системы, соединениях, сворачивании и появлении блоков. Непрерывное вращение, дрейф и каждый кадр движения не озвучивать; соседние события объединяются с минимальным интервалом 0,4 секунды.

`servo-motor` и `air-release` исключены из автоматического подбора. Вместо них изменения корпуса/подсистем получают одобренный UI-акцент или переход. `fan-start` оставлен только для запуска вентилятора, ровно с 50% прежней амплитуды (−6,02 dB после калибровки). Выключение не воспроизводит запуск повторно.

Тональная подложка сохраняется, амплитуда увеличена на 50%: 0,006 → 0,009 (+3,52 dB). Это относительные уровни до общего мастеринга, не проценты от максимальной громкости устройства. Голосовой PCM-мастер не меняется.

Исполняемые настройки: `src/lib/sound-preferences.ts`. Каждый новый `sound-cues.json` v4 сохраняет снимок настроек, коэффициент подложки и отдельный `levelScale` вентилятора. Worker использует их при следующих quality-v2 рендерах. Старые cue sheets без этих полей сохраняют прежнюю обработку. Само сохранение предпочтений не меняет старые MP4; Tesla обновляется отдельной аудиоревизией с резервной копией. Исходные скачанные записи/атрибуция остаются в библиотеке, но исключённые типы больше автоматически не выбираются.


## Уточнение · плавные хвосты и переходы · v5

Переход `soft-whoosh`, в том числе заставка, теперь ×0,5 относительно v4 (−6,02 dB после калибровки). Вентилятор остаётся ×0,5; подложка 0,009 сохраняется. В cue sheet v5 записываются плавные smoothstep-огибающие: вентилятор 0,04 с вход / 0,9 с выход; переход 0,02 / 0,2 с; акцент 0,02 / 0,16 с; появление 0,02 / 0,07 с. Затухание заканчивается в тишине с нулевой производной; поздний эффект затухает также на границе фильма. Старые cue sheets без полей сохраняют прежнюю короткую линейную огибающую.

## Уточнение · общий уровень эффектов · v6

По следующему запросу пользователя все дискретные эффекты дополнительно ослаблены на40% от текущей амплитуды (×0,6, −4,44 dB). Итоговый levelScale: появление и акцент0,6; вентилятор и переход0,3, поскольку их прежнее ×0,5 сохраняется. Плавные хвосты и частота событий сохранены. Тихая тональная подложка остаётся0,009, поскольку это отдельный фоновый слой, а запрос относится к эффектам. Голосовой мастер не меняется; общая нормализация микса по-прежнему −16LUFS. Настройки применяются к новым cue sheets; текущая Tesla получает отдельную аудиоревизию без новой речи и без рендера изображения.

## Уточнение · редкие повторы · v7 · 2026-10-19

Постоянное правило: один и тот же звук автоматически звучит не чаще одного раза в3секунды. Проверка идёт после выбора разрешённого эффекта, поэтому разные действия reveal/connect/hide, использующие один блип, не обходят ограничение. Лишние звуки удаляются, их таймкоды не переносятся: сохранённый акцент остаётся привязан к своему визуальному событию. Внутри группы приоритет у заставки, запуска вентилятора и выраженного изменения механизма. Непрерывное движение остаётся без повторных звуков. Если заметный повтор в сцене действительно требует отдельного эффекта, это отдельное явное решение постановки, а не автоматическое исключение из интервала.

Только для текущей аудиоревизии Tesla: ui-reveal ×1,5 от предыдущей версии (levelScale0,6→0,9), outro-transition ×0,5 (0,3→0,15). Другие whoosh, fan, акцент имени, голос и тональная подложка не меняются. Эти экспериментальные уровни не записываются как новые глобальные настройки. Старые cue sheets/экспорты не переписываются; новый — v7.

## Звуки сцены · v8 · 2026-10-19

Ранее механический акцент запускался по конечному ключу articulation. Теперь src/lib/scene-sound.ts берёт тот же интервал интерполяции, что и renderer: предыдущий ключ → новый ключ, с реальными anchorTime и word occurrence. Cutaway звучит во время подъёма/опускания, а не при достижении состояния. Lift/thrust получают акцент начала изменения; не озвучиваются удержание, камера, колёса и каждое небольшое изменение позы.

SoundCue поддерживает durationSeconds, durationMode:stretch|loop, playbackRate, automation и sync. Растяжение ffmpeg atempo подгоняет шумовой whoosh к точной длительности движения, включая плавные вход/выход; при интервале около1,2с исходные0,55с звучат примерно на половинной скорости. Голос через эту обработку не проходит. Loop сохраняет исходный запуск вентилятора один раз и затем повторяет установившуюся внутреннюю часть с перекрытием80мс. Громкость вентилятора следует smoothstep-интерполяции тех же fan keys: разгон → удержание → замедление → тишина. Интервалы обрезаются видимостью объекта и концом фильма; звук не переносится на другую главу и не обрывается за один сэмпл.

Все whoosh дополнительно уменьшены на20% по калиброванной амплитуде: глобальный levelScale0,3→0,24. В текущей Tesla финальная заставка сохраняет своё прежнее отдельное ослабление,0,15→0,12; её звук тянется на фактическую длительность перехода (0,8с в текущей Tesla). Блип текущей Tesla остаётся0,9, акцент имени0,6, вентилятор0,3, подложка0,009.

Повтор одного эффекта не чаще3с; протяжённый звук не перезапускается каждые3с, а остаётся одной записью на весь интервал. Два разных одновременных механизма могут звучать вместе по своим плановым диапазонам. Coincident generic blips уступают важному механическому событию. Старые cue sheets без новых полей обрабатываются как раньше. Снимки инструкций новых проектов хешируют scene-sound, sound-preferences и remix; существующие снимки не переписываются.


## Заставка @xtuned · 2026-10-19

Два новых типа эффекта только для заставки: `pixel-click` (kind `outro-click`, старт с начала нажатия после слова «xtuned», хвост 0,03 с) и `chiptune-arpeggio` (kind `outro-success`, на переключении кнопки, RMS −26 dBFS, хвост 0,15 с). Они берутся только из выбранных редактором файлов пака `xtuned-outro/v1` (снимок проекта), не ищутся в Openverse и не подменяются процедурным звуком. Клик и арпеджио — разные эффекты, поэтому стоят ближе 0,4 с; правило 3 с для одного эффекта сохраняется. Под заставкой звучат только её cue. Подробно: docs/creator-outro.md.

## Фоновая музыка обязательна · 2026-10-20

Тональная подложка 0,009 (C3+G3) заменяется по решению пользователя: каждое новое видео обязано иметь слышимую музыкальную подложку из `data/sound-packs/background-beds/v1`, выбранную по теме, построенную под длительность фильма и приглушаемую под голосом. Подробно: `docs/background-music.md`. Реализовано как cue sheet v9 (`musicBed`, тон отключён, стерео-premix); cue sheets без подложки остаются v8 и используют прежний тон.
