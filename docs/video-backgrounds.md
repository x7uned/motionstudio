# Фоны @xtuned · backgrounds/v1

Пользователь выбрал варианты **01–06, 08–10**. Вариант07 «Матовый графит» исключён. Исходные10 проб сохранены в `data/productions/2026-10-18-background-studies-v1`; исключение не удаляет историю выбора.

Утверждённая библиотека чистых PNG без аватара и текста: `data/backgrounds/v1/`. Каталог фиксирует названия, SHA-256 и версию исходника. Производственный статический SVG-рендерер: `renderer/StudioBackground.tsx`, контракт: `src/lib/backgrounds.ts`. Все девять рисунков соответствуют показанным пробам. Фон спокойнее в центре и виднее по краям; чёрная/фиолетовая/лавандовая палитра сохранена.

При создании обычного проекта сервер равномерно выбирает один из9 фонов через `crypto.randomInt`, затем сохраняет `{version:1,id,opacity:0.5}` в `profile.backgroundDesign` авторитетной SQLite-записи. Выбор не повторяется на кадре, главе, повторном рендере, починке картинки или ревью. Повторение того же варианта в разных роликах допустимо при случайном выборе. Номер07 не проходит контракт.

Фон монтируется отдельно от объектов и титров во всех основных рендерерах, тот же вариант используется на авторской заставке. Он статичен: нет миганий, дрейфа и случайности во времени. Предварительные PNG не содержат аватар: авторская шапка рисуется поверх фона один раз.

Старые профили без `backgroundDesign` сохраняют прежний вид. Сохранённый `tech-story/v1` не получает случайный фон. Новые снимки инструкций хешируют контракт и рендерер; backgrounds/v1 следует сохранять неизменным, следующие изменения оформлять новой версией.

Tesla `06650328-05fb-40cd-a25f-bd95a798a166` получает явно выбранный пользователем01 «Точечная матрица». Меняется только фон профиля: речь, сценарий, постановка, размер модели, нижняя компоновка и звуковой микс сохраняются. Предыдущий MP4 и профиль резервируются, новая версия проходит новое ревью с собственным SHA-256. Факт выбора фона не является одобрением готового видео.

По уточнению пользователя производственная непрозрачность фонового слоя снижена до50%: это значение по умолчанию для новых проектов и профилей с выбранным рисунком без явного opacity. Допустимое явное значение — от0 до1. Прозрачность применяется только к фону, включая заставку, поверх чёрной основы; аватар, текст и модель остаются непрозрачными. Исходные PNG каталога сохраняют полную силу рисунка; генератор чистой библиотеки явно задаёт opacity:1.
