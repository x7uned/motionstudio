# Проверка студии

Основная папка: `~/Desktop/Motion Studio`. С 2026-10-30 веб-интерфейса нет (решение пользователя; код только в теге git `web-ui-final`): студия — скилл `.agents/skills/motion-studio/SKILL.md` и CLI `npm run studio -- <команда>`, сетевого сервиса нет. Студия должна работать на macOS, Windows 10/11 и Linux.

## Как проверять сейчас

- `npm run check` (TypeScript), `npm test`, `npm run secrets:check` (секреты не попали в файлы).
- При изменениях конвейера — настоящий прогон: `npm run studio -- create …` → `npm run studio -- run <id>` → ревью кадров финального MP4 (`npm run studio -- report <id>`, при необходимости `review <id>`).
- Экспортированный MP4 воспроизводится целиком плеером ОС (файл с диска) от начала до конца со звуком. Просмотр статичных кадров — не полная проверка воспроизведения.
- Технический проход и критика модели не равны одобрению: принимает только редактор (`approve <id> --quote "…"`).

## Запись проверки 18 октября 2026 (тогда — с веб-интерфейсом)

Тогда студия работала как локальная веб-панель Next.js (адрес `127.0.0.1:3210`); всё ниже — история, а не инструкция.

- TypeScript и production-сборка Next.js проходили.
- 6 тестов проходили: точный таймлайн, длинная речь, безопасные цвета, очередь без дублей, снимок профиля, изоляция служебного окружения Codex.
- 9 HTTP-проверок проходили: Range-видео и перемотка, ошибочный диапазон, запрет выдачи базы и выхода за папку, защита от внешнего Origin, проверка параметров и ID, проверка сигнатуры изображения, отсутствие побочных записей при отклонённых запросах.
- В браузере проверены создание проекта, загрузка JPG, вставка транскрипта, анализ профиля, библиотека, возврат на доработку, принятие, мобильное меню и компоновка при 390 px без горизонтального скролла.
- Незавершённые задачи сохранялись и продолжались после перезапуска. Удалённое из активных изображение возвращено и снова архивировано; файлы сохранены.
- Анализ изображения и транскрипта из тестовых материалов завершился за 8,65 с после изоляции CLI. Результат и журнал событий: `qa/extracted-profile.json`, `qa/style-analysis-run.json`.
- Все 148 оригинальных файлов результатов совпадают с архивом по SHA-256; дополнительно создан портретный постер. В папке сохранены 19 motion skills. См. `archive-manifest.json`.

### Сквозной прогон

Через тогдашний веб-интерфейс создан ролик «Как работает API: заказ в кафе»:

- 1080×1920, ровно 30,00 с, 900 кадров, 30 fps.
- 5 сцен, русский голос Svetlana Neural, тихая музыка и акценты.
- Все 5 фрагментов речи укладываются в свои сцены без ускорения.
- Экспорт H.264 High, yuv420p, BT.709 limited, AAC stereo 48 kHz.
- Измеренная громкость −16,22 LUFS, true peak −4,49 dBTP.
- Полное декодирование проходит. Проверка кадров моделью: pass, с необязательными предложениями по стрелкам и служебным подписям.
- Файл воспроизведён в тогдашней панели от начала до конца: ended=true, currentTime=duration=30, error=null, muted=false.
- Последний кадр остаётся читаемым. Контактный лист всех 30 секунд снят с шагом 0,5 с и просмотрен.
- Проверены первые и последние кадры обоих форматов 9:16 и 16:9. Сквозной экспорт и воспроизведение проверены для 9:16; 16:9 проверен по рендеру кадров.
- После исправления хвоста AAC все видеопакеты совпадают с исходным рендером по SHA-256; изменена только длительность аудиодорожки в контейнере.

Демо принято редактором в рамках QA. Материалы реального автора ещё не предоставлены. Тестовые референсы убраны из активных, текущий профиль возвращён к «Студийному». Анализ примеров не является обучением весов модели.
