# Генераторы изображений: пробный маршрут

Решение пользователя 2026-10-21: «попробуем» генераторы картинок, начиная с **Krea (MCP)**. Основа — справочник vizavi_motion `references/image-providers.md` (исследование документации от 16.10.2026, без практических тестов). Пока это эксперимент: ни один рендерер студии не использует сгенерированные изображения, конвейер их не заказывает.

## Правила

- Аккаунты, оплату и ключи создаёт только пользователь. Агент не регистрируется, не вводит пароли и не запускает платные кредиты без явного «да».
- Ключи — только в `.env.local` (как ElevenLabs/Tavily/Apify); не печатать, не копировать в выходы, не передавать ролям.
- Сгенерированное изображение — ассет (PNG), а не код. Сохраняй его с происхождением: сервис, модель, промпт, дата, условия использования, SHA-256.
- Никогда не выдавай сгенерированную картинку за фотографию реального события, человека или продукта. Логотипы и фото людей — только плитками из Wikimedia Commons (docs/illustrated-renderer.md).
- Для серии одного героя каждый раз подавай один и тот же канонический набор референсов, а не последнюю перегенерацию (иначе дрейф).
- Прозрачность проверяй по-настоящему: альфа-канал, край на светлом и тёмном фоне. Нарисованная «шахматка» — не прозрачность.

## Krea — первый кандидат

- MCP: `https://api.krea.ai/mcp`, вход OAuth аккаунтом Krea ([инструкция](https://www.krea.ai/docs/developers/mcp)). В каталоге коннекторов Claude его нет — подключать как свой MCP-сервер.
  - Claude Code в терминале: `claude mcp add --transport http krea https://api.krea.ai/mcp`, затем `/mcp` → войти.
  - Claude desktop: Настройки → Коннекторы → добавить свой коннектор с этим адресом.
- MCP через OAuth тратит compute units рабочего пространства; API-токен — отдельный платный баланс. Не смешивать.
- Free: 100 units в день (ориентир страницы — около 25 картинок Klein или 5 Krea 3). Это не гарантия числа правок по референсу.
- Коммерческая лицензия — на платных планах; Free считать маршрутом личных проб.
- Нативная альфа не подтверждена: фон удалять локально и проверять край.

## Резервные маршруты

| Маршрут | Условия (на 16.10.2026) |
|---|---|
| Cloudflare Workers AI, FLUX.2 Klein 4B | Free 10 000 neurons/день (не число картинок), REST, до 4 референсов меньше 512×512. Нужен токен пользователя. |
| ChatGPT / Gemini в браузере | Через встроенный браузер под входом пользователя. Это не бесплатный API. |
| Leonardo, Ideogram, Recraft, Hugging Face | Ограниченные free-планы, работы часто публичные, коммерческая лицензия не всегда. |

Лимиты меняются — перед использованием проверь страницу тарифа и запиши дату проверки.
