# Кадр · Motion Studio

Новые проекты используют **режим качества v2**: цельный рассказ до сцен, отдельные редактор и фактчекер, план подачи голоса, Claude для постановки и проверка кадров из итогового MP4. В Настройках доступно слепое сравнение трёх голосовых вариантов после просмотра стоимости; готовые образцы и выбор не создаются автоматически. Подробности и ограничения: [docs/quality-pipeline.md](docs/quality-pipeline.md).

Локальная студия коротких объясняющих роликов. Next.js, SQLite, Codex, Remotion, FFmpeg и русская озвучка. Основная рабочая папка: `~/Desktop/Motion Studio`.

## Через агента (рекомендуемый путь)

Скажите Claude Code, Codex или другому чат-агенту в этой папке: «сделай видео про … по шаблону …». Агент работает по скиллу `.agents/skills/motion-studio/SKILL.md` и CLI `npm run studio -- …`: сам пишет исследование, сценарий и постановку, студия озвучивает и рендерит. Агент спрашивает только об аккаунте, платных повторах и об одобрении. Подробно: [docs/agent-mode.md](docs/agent-mode.md).

```sh
npm run studio -- start     # движок без веб-интерфейса (в терминале пользователя)
npm run studio -- status    # движок, слот рендера, активные задачи, настройки
npm run studio -- ui        # веб-интерфейс на 127.0.0.1 — когда хочется посмотреть
npm run studio -- config get  # настройки скилла (studio.config.json, без секретов)
npm run studio -- stop      # остановить движок между задачами
```

Ролики идут параллельно; строго по одному идёт только локальный рендер.

## Запуск UI и движка вместе

Дважды нажмите **Открыть студию.command** в папке студии. Откройте **http://127.0.0.1:3210**. Терминал должен оставаться открытым: в нём работают сервер и очередь. Повторный запуск откроет уже работающую студию.

Из терминала в этой папке:

```sh
npm start
```

Для разработки: `npm run dev`. Для пересборки: `npm run build`. Проверки: `npm run check` и `npm test`.

На этом Mac уже установлены зависимости и собрана production-версия. Нужны Node.js с `node:sqlite` (проверено на 26.7), Google Chrome, вход в Codex и интернет для генерации/анализа/речи. FFmpeg для Apple Silicon находится в `bin/`. После переустановки зависимостей запустите `scripts/setup.sh`. Учётные данные в папку не копируются.

## Создать ролик

1. В «Студии» введите тему и конкретный пример, на котором её объяснить.
2. Выберите 9:16 или 16:9, 30/45/60 секунд и русскую озвучку.
3. Нажмите «Создать ролик». Движок создаст сценарий, речь, анимацию и результаты проверки; другие ролики в это время идут параллельно, локальный рендер — по одному.
4. В редакторе можно менять заголовки, произносимый текст и визуальный приём каждой сцены. После сохранения запустите «Рендерить заново».
5. В «Ревью» посмотрите проверки и кадры. Проиграйте видео целиком. Примите ролик либо оставьте комментарий и верните на доработку. Комментарий сохраняется для редактора; правки текста вносятся в сценарий.

Изменённый сценарий не считается актуальным видео до нового рендера. Технический pass и отзыв модели не заменяют решение редактора. Архивные видео доступны в библиотеке, их исходники — в `archive/2026-10-18`.

## Стиль автора

В «Стиле автора» загрузите кадры/скриншоты JPG, PNG, WebP и транскрипты TXT, SRT, VTT; транскрипт можно вставить текстом. Изображения проверяются и преобразуются в JPG, исходные имена сохраняются в базе. Один файл до 15 МБ; текст до 100 000 символов.

«Извлечь стиль» анализирует до 8 последних изображений и 8 транскриптов: палитру, композиционные приёмы, характер хука, фразы, объясняющие примеры и финал. Правила доступны для ручной правки. Материал можно убрать из активных и сразу вернуть; файл сохраняется на диске.

Для сценария модель получает снимок профиля и до 4 последних активных транскриптов. Рендер использует проверенные шаблоны, палитру и один из локальных шрифтов. Новый сложный визуальный приём добавляется как отдельный шаблон в `renderer/`, после просмотра референсов. Точная копия любого дизайна автоматически из одного изображения не обещается.

Профиль применяется к новым проектам. Старые проекты хранят собственный снимок профиля, поэтому их рендер остаётся воспроизводимым.

Сейчас это **правила + примеры в контексте**, без обучения весов модели. Для следующего этапа соберём эталонные транскрипты, примеры принятых сценариев и повторяющиеся замечания. Затем сравним новые сценарии по одному рубрикатору. Дообучение имеет смысл рассматривать, если устойчивые ошибки остаются после настройки контекста; оно не заменяет шаблоны анимации и проверку таймингов. Подробности в `docs/author-style.md`.

## Где лежит работа

| Путь | Содержимое |
|---|---|
| `archive/2026-10-18/` | Все предыдущие видео, сценарии, ZIP и переносимые исходники из этого чата |
| `data/studio.sqlite` | Проекты, очередь, референсы, события и текущий профиль |
| `data/projects/<id>/storyboard.json` | Редактируемые сцены и единый таймлайн |
| `data/projects/<id>/context.json` | Профиль и примеры, переданные генератору |
| `data/projects/<id>/video.mp4` | Готовый экспорт |
| `data/projects/<id>/audio.wav`, `alignment.json` | Озвучка, музыка и границы речи |
| `data/projects/<id>/contact-sheet.jpg`, `review.json` | Кадры и проверка |
| `data/references/` | Визуальные материалы, в том числе убранные из активных |
| `.agents/skills/` | Снимок 19 установленных motion skills из двух репозиториев |
| `renderer/` | Детерминированные шаблоны Remotion |
| `scripts/worker.ts` | Движок: параллельная очередь и этапы производства (рендер — в одном слоте) |
| `studio.config.json` | Настройки скилла (`npm run studio -- config get`), без секретов |

В архиве оставлены оригиналы. Новая студия не меняет предыдущие исходники. Для резервной копии остановите студию и скопируйте всю папку; так SQLite и файлы попадут в согласованный снимок.

## Важные границы первой версии

Это локальная однопользовательская студия, привязанная к `127.0.0.1`. Публикация в соцсети и командный доступ ещё не подключены. Внешние сервисы используются для Codex и синтеза речи Edge TTS; без интернета доступны библиотека и редактор. Выбранные изображения/тексты передаются Codex для анализа, а текст речи — сервису TTS.

Ролики используют набор типографических и схемных шаблонов, а не генерацию произвольного исполняемого кода. Результат следует просматривать редактору, особенно факты и смысл объяснения. Автоматическое визуальное ревью видит контактный лист, а не движение и звук.

Пути инструментов можно переопределить через `STUDIO_CODEX`, `STUDIO_FFMPEG`, `STUDIO_CHROME`, `STUDIO_PYTHON`; порт через `PORT`. Ключи и токены в проекте не нужны. Статус подключения виден в «Настройках».

## Разборы видео

В разделе «Разборы видео» добавляйте 1–20 ссылок на конкретные Reels разных авторов. Выберите шаг 0,5 или 1 секунда: система скачает ролики, распознает речь и последовательно разберёт все кадры. Результат включает сценарий по сценам, композицию, движение камеры/объектов, свет и план реализации, включая 3D. Подробности и ограничения: [docs/video-references.md](docs/video-references.md).

## 3D-рендер

В разделе «3D-рендер» доступны процедурные модели, загрузка своих GLB/embedded GLTF и тестовый ролик. При создании проекта выберите 3D или подборку с 3D-разборами. Отдельный motion-режиссёр Claude Opus 5.5 (Extra High) составляет проверенный план камеры, моделей и света, затем Three.js/Remotion выпускает MP4 с титрами и общим таймлайном озвучки. Подробности, ограничения и формат плана: [docs/3d-renderer.md](docs/3d-renderer.md).

## Роли моделей

| Роль | Модель | Как вызывается |
|---|---|---|
| Поисковые запросы, исследование, сценарий | GPT‑6.1 Sol · xhigh | Codex CLI, изолированный запуск |
| Разбор референсов, ревью контактного листа | GPT‑6.1 Sol | Codex CLI |
| 3D-режиссёр, motion-план сетевых сцен | Claude Opus 5.5 · xhigh | Claude Code CLI (`src/lib/claude-provider.ts`) |

Claude запускается в `--restricted` режиме: без shell, MCP, настроек пользователя и истории сессий, в отдельной временной папке, со строгой JSON Schema. Секреты ElevenLabs/Tavily/Apify и переменные чата Claude не передаются. Подмены модели нет: если Claude недоступен, задача останавливается с понятной ошибкой.

Один раз войдите в Claude Code из Терминала (подписка Claude или API-ключ):

```sh
"$HOME/Library/Application Support/Claude/claude-code/"*/*/claude.app/Contents/MacOS/claude auth login
```

Путь к CLI можно задать через `STUDIO_CLAUDE`. Статус виден в «Настройках → Motion-режиссёр».
