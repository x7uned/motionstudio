# Кадр · Motion Studio

A working production desk for short explainers. The signature is the visible path from topic to reviewed film, paired with a real library of work.

- Slate 900 sidebar, slate 50 canvas, white surfaces. Blue 600 is the one primary action color; green/orange are reserved for status.
- Manrope headings, Inter body. Both loaded locally with Cyrillic. No network font fetch.
- A 238 px navigation rail; main content at most 1500 px. Topic composer and five-stage production strip lead the studio screen.
- Border-led surfaces, restrained radii, no decorative glows or gradients. 16–24 px interior rhythm, 20–24 px between sections.
- Labels describe actual work. Never invent queue progress, provider availability, project counts, or completed checks.
- At <=800 px use the navigation drawer; at <=620 px stack the composer, project preview, and editor. Native controls, visible keyboard focus, reduced motion, and inline errors.
- Video aesthetic is separate from admin aesthetic. Each project snapshots its style profile. Editing a profile affects future projects, not old renders.
