# Естественная русская озвучка · проверено 18 октября 2026

Для текущего черновика используется уже доступная ru-RU-SvetlanaNeural через Edge TTS. Это облачная озвучка без ключа в нашем локальном инструменте, а не модель, размещённая на этом Mac. Качество субъективно; роботизированный тембр нельзя исправить только эквалайзером. Текущий улучшенный подход: разговорный текст, целые фразы, паузы по пунктуации, анимация по меткам слов, отсутствие дополнительного ускорения при монтаже.

## Что рекомендую для следующей итерации

Сначала выбрать 2–3 русскоязычных голоса ElevenLabs и сравнить один и тот же 15-секундный фрагмент с терминами «репозиторий», «непрерывная интеграция», «развёртывание». Начать со стабильной Multilingual v2 и сравнить с текущей выразительной v4. На момент проверки документация уже называет v4 основной моделью; v4 доступна через Text to Dialogue API, поэтому нельзя просто подставить её ID в старый TTS-запрос без проверки. Для одной спокойной дикторской дорожки Multilingual v2 остаётся разумным первым тестом. Это рекомендация для прослушивания, не результат локального сравнения качества.

Free: 10k кредитов в месяц, без коммерческой лицензии и с обязательной атрибуцией при публикации. Starter: 30k кредитов, коммерческая лицензия; обычная месячная цена на странице $6, акционная цена первого месяца показана отдельно. Налоги исключены. Точную стоимость минутного ролика считать по выбранной модели, длине текста и числу перегенераций, не по условному числу «минут в тарифе».

Для полностью локального пути первым испытывать Chatterbox Multilingual, а не английские Turbo/Nano. MIT-лицензия репозитория и поддержка ru подтверждены официальным README. Бесплатны веса/код, но не вычисления, время настройки и сервер при размещении в облаке. Не обещать качество ElevenLabs без A/B-прослушивания конкретных голосов. Не клонировать голос автора видео; можно использовать собственную запись пользователя или голос, на который есть разрешение.

## Как подключить, не ломая синхронизацию

1. Ключ хранится только в локальном серверном окружении; не в браузере, JSON сценария, ZIP исходников или git. Пользователь вводит его на своей машине, не отправляет в чат.
2. Выбираем voice_id и провайдер в настройке рендера. Фиксируем модель, темп и словарь произношений на весь фильм.
3. Генерируем сначала речь целыми смысловыми фразами. Для ElevenLabs использовать endpoint с timestamps; для v4 сверить Text to Dialogue with timestamps. Кэшировать результат по тексту, голосу, модели и настройкам.
4. Полученные метки нормализуем в наш alignment.json: text/start/end для каждого слова. Для другого голоса старые метки не переиспользуются.
5. Под длительности речи пересчитываем storyboard.json на 30 fps. Если сумма больше минуты, сокращаем текст, не сжимаем голос насильно. Добавляем короткий финальный hold.
6. Потом рендерим картинку и мягкие сигналы, проверяем все границы реплик, громкость после AAC и реальное проигрывание.

Адаптер ElevenLabs пока не подключён и генерации через него не оплачивались. Self-hosted модели пока не скачаны и не замерены. Это варианты для следующего выбора; готовый текущий фильм использует Светлану.
