# Исследование → сценарий → видео

Все НОВЫЕ проекты проходят подготовку до озвучки и рендера. Старый или вручную отредактированный storyboard при повторном рендере сохраняется. Чтобы подготовить новую версию с исследованием, создайте новый проект с той же темой.

## Роли и последовательность

1. Планировщик поиска: отдельный изолированный запуск GPT‑6.1 Sol / xhigh. Сжимает тему до реального вопроса, предлагает два коротких запроса и домены первоисточников. Произвольный код и браузерные инструменты у модели выключены.
2. Tavily Search + Extract: сервер выполняет запросы, предпочитает разные официальные домены и читает 3–5 страниц. Сниппет поиска не считается проверкой факта. Если прочитано меньше трёх источников, процесс останавливается до озвучки.
3. Исследователь: отдельный GPT‑6.1 Sol / xhigh. Получает прочитанные материалы и правила Content Research Writer. Возвращает факты, короткие дословные подтверждения, оговорки, спорные утверждения, три угла подачи и десять вариантов начала. Цитаты программно сверяются с текстом страниц, ID ссылок проверяются.
4. Сценарист-режиссёр: отдельный GPT‑6.1 Sol / xhigh. Использует исследование, Script Lite, Short Video Scripter и правила @xtuned. Выбирает начало автоматически; альтернативы сохраняются. Пишет русский текст на 30/45/60 с, экранные подписи, описание изображения, схему и моменты её изменений. Любой новый факт привязывается к исследованию. Чужие рекламные интервью, upsell и маркетинговые реестры не включаются в процесс студии.
5. Валидатор: проверяет контракт JSON, ID фактов, узлы/связи, свободные ячейки, слова-сигналы и границы событий. Сценарий не является исполняемым кодом.
6. Озвучка и рендер: прежний ElevenLabs/Edge адаптер, бренд, 30 fps и правило плавных появлений. Рендер реально читает diagram и beats сценария. Для событий cue используется фактическая метка слова из озвучки, а at — резервное время относительно начала сцены. Без голоса используется временной план.
7. Проверки файла, кадров и редакторское ревью. Автоматические проверки не равны пользовательскому одобрению или независимому фактчекингу всех выводов.

## Что хранится в проекте

- `research-query.json` — намерение поиска, запросы, домены;
- `search-*-raw.json`, `extract-raw.json`, `source-fetch.json` — результаты поиска, прочитанные страницы и неудачные извлечения;
- `sources.json` — текстовые материалы с URL и временем чтения;
- `research.json`, `research.md` — подтверждения, оговорки, три угла и десять начал;
- `script-package.json` — полный сценарий и собственная проверка сценаристом;
- `storyboard.json` — редактируемый, валидированный план для рендера;
- `script.md` — таблица время / озвучка / изображение / текст, затем события схемы. После синтеза обновляется по фактическим таймингам;
- `pipeline.json` — использованные роли, модель, effort и выбранные варианты;
- `query-agent/`, `research-agent/`, `script-agent/` — структурированные ответы и технические события без записи скрытых рассуждений.

Материалы — в папке проекта и в `npm run studio -- report <id>` (бывшая вкладка «Источники»), план показов — `scenes <id> show` (бывший «Сценарий»). Подписи узлов можно редактировать (`scenes <id> export <файл.json>` → правка → `scenes <id> save <файл.json>`); изменения не должны ломать ссылки на слово в речи. Прочитанные материалы кэшируются до 24 часов; готовый сценарий не переписывается при обычном повторном рендере.

## Навыки и инструменты

Установлены Script Lite, Short Video Scripter, Content Research Writer, Tavily Search, Extract, Research, CLI и Best Practices. Версии Git-коммитов: `research-skills.json`. Навыки установлены и глобально в Codex, и локально в `.agents/skills`; worker читает локальные инструкции явно. Персональная память пользователя не изменяется.

Официальный `tavily-cli==0.1.8` установлен в отдельное `.runtime/research`. Обычный поток использует Search + Extract; они могут работать без авторизации в пределах бесплатного лимита. Превышение лимита не запускает логин в фоновой очереди. Подключить учётную запись вручную:

```sh
.runtime/research/bin/tvly login
```

Либо пользователь добавляет `TAVILY_API_KEY` в локальный `.env.local`. Не передавайте ключ аргументом команды или в чат. `Tavily Research` установлен как дополнительный инструмент для глубокого исследования; его прямой вызов требует авторизации и не включается автоматически в каждый короткий ролик.

Ключ Tavily передаётся только Tavily CLI; ключ ElevenLabs — только процессу озвучки. Оба удаляются из окружения изолированных запусков Codex. Сценарий использует существующий локальный вход Codex, отдельный OpenAI API key для этого потока не требуется. Доступность конкретной модели проверяется фактическим запуском, без автоматической подмены на другую модель.

## Ограничения первой версии

Узлы схемы используют проверяемую сетку 2×3 и ограниченный набор объектов. Это детерминированный шаблон, а не произвольная генерация визуального кода. Режиссёрские схемы подключены к вертикальному explainer-шаблону. Числа, заявления об исключительности и обещания результата нельзя добавлять ради хука. Дословное совпадение цитаты проверяется автоматически; смысловую достаточность доказательства всё равно оценивает редактор.
