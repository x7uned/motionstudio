# Подключение ElevenLabs

Локальная конфигурация `.env.local` читается только сервером. Ключ не передаётся клиенту, генератору сценария или в результаты. Файл исключён из Git и архивов. Не присылайте ключ в чат.

```dotenv
STUDIO_TTS_PROVIDER=elevenlabs
ELEVENLABS_API_KEY=
ELEVENLABS_VOICE_ID=
ELEVENLABS_MODEL_ID=eleven_multilingual_v2
```

1. Вставить ключ в `.env.local`. Выбрать доступный аккаунту русский голос; ID указать в `ELEVENLABS_VOICE_ID`. Для просмотра доступных голосов: `node --env-file=.env.local --import tsx scripts/eleven-voices.ts`. Команда только читает список, не генерирует платную речь.
2. Перезапустить `npm start` после изменения провайдера. Worker дополнительно читает последние значения файла при каждом запуске Python; ключ не выводится в лог.
3. В настройках «Готов к проверке» означает только заполненную конфигурацию. Успешное подключение подтверждается реальным ответом API и готовой дорожкой, а не наличием строки ключа.
4. Новый рендер отправляет весь сценарий одним запросом в TTS with timestamps. Модель multilingual_v2, speed 1.0; русский задаётся текстом и выбором голоса. Для v2 не передаём несовместимый language_code.
5. Успешный результат сохраняется в папке проекта: повторный рендер с тем же голосом/текстом/настройками использует кэш. После неясной сетевой ошибки платный запрос автоматически не повторяется. Проверьте историю ElevenLabs перед ручным повтором.
6. Реальные character timestamps превращаются в слова, сохраняется пунктуация. Голос сохраняется одним непрерывным PCM-мастером; границы сцен ставятся между словами. Не нарезать и не раскладывать каждую главу с новым отступом. Если натуральная речь с паузами не помещается в минуту, рендер останавливается с просьбой сократить текст.
7. `speech-provider.json` показывает фактически использованный провайдер и модель. Никакого молчаливого отката на Edge. Для временного превью можно явно записать `edge` в `data/projects/<id>/tts-provider.txt`; это отмечается в метаданных проекта, файл следует убрать перед финальным ElevenLabs-рендером.

Голос из библиотеки не копирует диктора референса. Для собственного клона нужны права и соответствующее разрешение владельца голоса.

Официальная документация: https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps

## Ритм речи и голос по умолчанию

Готовый голос библиотеки Alexey - Character, русский разговорный, ID gRp20jh5cr1dR3Lhhapi; не личный dennis. Успешно добавлен через официальный Voice Library API. Без повышенного тарифа (rate=1). Предел сцены определяется измеренной речью, длительность проекта сокращается до целой секунды. Не заполнять оставшийся бюджет тишиной. Только середины внутренних пауз длиннее 1,1 с сокращаются; слова и скорость не меняются. Проверять speech-rhythm.json и narration.wav: все межсловные и межглавные паузы <=1,5 с.

## Непрерывный рассказ

Весь произносимый текст склеивается пробелами в один абзац и отправляется одним запросом. Multilingual v2: stability 0.55, similarity 0.75, style 0, speed 1.0. Сохранить интонацию и естественные промежутки исходного дубля; вставленная тишина между главами равна нулю. Только паузы длиннее 1.1 с допускают удаление тихой середины. Границы сцен следуют реальным меткам речи с округлением до кадра. Мягкие сигналы смены главы понижены под голосом. Сценарий писать как связное объяснение, не список вопросов. Значения настроек являются выбранным вариантом, не гарантией субъективного качества; финальную интонацию оценивает пользователь.


Уточнение для длинных выпусков: пользователь разрешил исторический ролик примерно 150 с. В студии добавлен выбор 2:30, технический предел длинного объяснения 180 с, предел главы 30 с. Обычный Shorts остаётся до60 с. Длительность по-прежнему верхний бюджет, без растягивания паузами; весь голос одним дублем, естественная скорость. Исторические фото подписывать реальной датой, хранить URL и условия использования. Иллюстрация 1928 года не является снимком станции 1878 года.


После записи естественного дубля проверка количества слов использует исходный requested budget из duration-budget.json, а не получившуюся сокращённую длительность. Например,100слов могут естественно занять46с при минутном бюджете. Не ускорять и не перезаписывать уже успешный дубль ради эвристики words/second; фактическое попадание в бюджет проверяется отдельно по PCM, словам и конечным кадрам. Сохранение правок после рендера также учитывает исходный бюджет.
