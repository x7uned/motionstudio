# Motion Studio · звуки заставки @xtuned · outro-8bit-01

Создан 2026-10-19. Кандидаты для прослушивания, не утверждённый production-пак.

Запуск из этой папки: `python3 serve.py`, затем http://127.0.0.1:3212 (только loopback). Оценки сохраняются в `ratings.json`.

- 01–06: пиксельный клик — нажатие кнопки «Подписаться» / «Follow» сразу после слова «xtuned».
- 07–13: короткое арпеджио — кнопка становится «Вы подписаны ✓» / «Following ✓», персонаж радуется.

Kenney (CC0-1.0) берутся из `../audition-01/sources` без изменения исходников. Синтезированные пробы 05, 06, 11–13 — оригинальные, построены `build.py` из band-limited pulse-волн, с плавным хвостом. Мягкий whoosh на входе уже утверждён и здесь не выбирается.

`build.py` воспроизводит файлы и `manifest.json` (SHA-256, усиление, пики). Ключи и платные сервисы не используются. Победителя выбирает редактор; до выбора заставка не регистрирует звуки в каталоге.
