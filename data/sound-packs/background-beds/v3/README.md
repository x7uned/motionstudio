# Фоновые подложки · background-beds/v3 · аранжировка по сюжету

Сохранено 2026-10-21 после демо `work/vizavi-demo`: пользователь одобрил музыку как композицию и работу
эффектов («отличная работа с музыкой… с эффектами отличная»). Те же тембры, что в v1/v2, но подложка больше
не петля: она строится заново под каждый фильм из его собственного плана.

- **Вступление** тонкое (пэд и приглушённая мелодия), грув входит со второй главы.
- **Главы** меняют гармонию; фраза начинается с главы.
- **Повреждение** (warn-выноска режиссёра) — провал: глухой удар и три падающие ноты, мелодия и ударные уходят.
- **Восстановление** (ok-выноска) — подъём: колокольчики вверх, грув возвращается.
- **Крупное слово** — звон «сборки».
- **Последняя смысловая глава** — финальный аккорд ровно на долю (темп подстраивается в пределах ±6 %),
  дальше звучит хвост, к заставке музыка уходит: под заставкой только её звуки.

`generator/arranged.mjs` — chip-soft, pluck-curious, glass-arp, warm-pad, space-drone, lofi-pulse, music-box.
nature-air остаётся статичной (`generator/beds.mjs`). `audio/*-qr-arrangement.m4a` — прослушки: каждая
подложка, аранжированная по плану QR-ролика 401596f0 (94 с, −20 LUFS). Правила: `docs/background-music.md`,
`src/lib/music-arrangement.ts`. Пакет не переписывается; изменения — v4.
