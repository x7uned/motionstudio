# Фоновые подложки · background-beds/v5 · бесшовная петля

Сохранено 2026-10-22. Пользователь попросил закольцованный иллюстрированный ролик для World If Then («One minute on Earth»): последний кадр переходит в первый. По правилу «Концовка» (`docs/publishing-and-retention.md`) музыка в таком ролике идёт через стык без затухания и целым числом циклов.

- Тембры, гармония, грув, провалы и одиночные акценты — как в v4 (правила аранжировки 2).
- Режим петли (`arrangement.loop=true`, `src/lib/music-arrangement.ts`):
  - грув с первой доли, без тонкого вступления;
  - нет финального аккорда и нет затуханий в начале и в конце;
  - темп подогнан так, что в фильм входит целое число тактов;
  - последний такт — доминанта, она разрешается в первый аккорд следующего круга.
- Как собирается: генератор играет аранжировку три раза подряд и вырезает средний проход. Его первые 0,5 с плавно переходят из настоящего продолжения его конца. Поэтому последний сэмпл переходит в первый, а хвосты нот и реверберации звучат через стык.
- Приглушение под голосом (`duckBed`) в петле начинает с того состояния, которым заканчивается, и тоже не затухает.
- Без `loop` выход генератора совпадает с v4 байт в байт. v5 выбирается только для проектов с `--ending loop`; остальные новые проекты остаются на v4.

Прослушки — те же файлы v4 (`../v4/audio`). Пакет не переписывается; изменения — v6.
