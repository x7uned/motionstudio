# Фоновые подложки · background-beds/v4 · одиночные акценты

Сохранено 2026-10-21. Пользователь услышал в роликах повторяющийся тройной звон «готово» (акцент «подъём» v3:
три колокольчика вверх с шагом 0,45 с на каждой зелёной выноске) и попросил, чтобы звук соотносился с действием
на картинке и не был тройным. Тембры, гармония, грув, провалы и финальный аккорд — как в v3.

- **Каждый акцент — один звук** ровно на своём событии картинки (никаких трёх нот подряд):
  - провал — один глухой удар с одной падающей нотой, на красной (warn) выноске; мелодия и ударные уходят;
  - подъём — один колокольчик, только там, где зелёная (ok) выноска закрывает провал (видимое решение);
  - крупное слово — один звон;
  - финальный аккорд — аккорд (одновременные ноты), как в v3.
- Обычные зелёные выноски получают свой UI-блип появления, а не музыкальный акцент (правила аранжировки 2,
  `src/lib/music-arrangement.ts`; v3 остаётся на правилах 1 байт в байт).

`generator/arranged.mjs` отличается от v3 только блоком акцентов; `generator/beds.mjs` (nature-air) без изменений.
`audio/*-qr-arrangement.m4a` — прослушки v4 по плану QR-ролика 401596f0 (94 с, −20 LUFS).
Пакет не переписывается; изменения — v5.
