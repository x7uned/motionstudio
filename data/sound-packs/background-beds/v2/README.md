# Фоновые подложки · background-beds/v2

Сохранено 2026-10-20. v1 без изменений (те же байты и SHA-256) плюс три подложки для explainer-роликов,
выбранные пользователем после прослушивания на ролике про QR-код (слова — в `selection.json`).
Оригинальный процедурный синтез, без сторонних сэмплов; генераторы детерминированы (повтор проверен байт в байт).

| id | с версии | статус | для чего |
|---|---|---|---|
| **pluck-curious** | v2 | explainer | щипковое арпеджио 90 BPM — «как это работает», устройства |
| **glass-arp** | v2 | explainer | стеклянное арпеджио 100 BPM — технологии, алгоритмы, момент открытия |
| **chip-soft** | v2 | explainer | мягкий 8-bit 110 BPM — QR, пиксели, компьютеры, интернет |
| **warm-pad** | v1 | предпочтительный | история, спокойные объяснения |
| **space-drone** | v1 | предпочтительный | космос, what-if масштаба планеты |
| **lofi-pulse** | v1 | предпочтительный | быт, лёгкие бодрые ролики |
| music-box | v1 | сохранён | только явным выбором |
| nature-air | v1 | сохранён | только явным выбором |

- `audio/*.wav` — 120 с, 48 кГц stereo PCM24, −20 LUFS; SHA-256 и `gainDb` в `manifest.json`.
- `generator/beds.mjs` (v1-подложки) и `generator/explainer.mjs` (v2) — `node <gen> <id> <seconds> <out.f32>`.
- `generator/duck.mjs` — скрипт демо; в пайплайне то же приглушение делает `src/lib/music-beds.ts`.
- Правила выбора и сведения: `docs/background-music.md`. Этот пакет не переписывается; новые подложки — v3.
