# BRIEF · «Карандашный скетчбук»

<задача>
Пробный стиль для Motion Studio: 15-секундный немой вертикальный ролик 1080×1920, 30 fps, по общей истории
work/style-lab/story.json «Как сообщение доходит до друга». Один постоянный рисунок на странице тетради
(без перелистываний): ноутбук внизу, три маршрутизатора посередине, сервер и телефон друга вверху.
Подписи — ровно тексты битов, по их времени. Пишу только в renderer/style-lab/sketch и work/style-lab/sketch.
</задача>

<стиль>
Тетрадь в клетку: тёплая бумага #F4EEDF, голубая сетка, розовая линия полей, мягкая виньетка, зерно бумаги.
Графитовые/чернильные штрихи Rough.js (фиксированный seed для каждой фигуры, «кипение» линии — смена seed
каждые 4 кадра из 3 вариантов). Инфраструктура — нейтральная серая штриховка; цвет несут только пакеты
(персик, мята, небесный, сирень). Один сильный акцент — фиолетовый бренда #8D59DA (кнопка, проверка номеров,
галочка), маркер-выделитель — жёлтый бренда #F4CA50 под подписью. Рукописный Caveat 700 (локальный @fontsource).
Всё появляется прорисовкой (stroke-dashoffset через pathLength=1), штриховка заполняется «каракулями»,
подписи пишутся слева направо мягкой маской. Ничего не появляется и не исчезает за один кадр.
</стиль>

<референсы>
Образовательные скетч-ролики (whiteboard / notebook explainers), заметки-стикеры, ножницы-дудл, пунктирные
маршруты цветным карандашом. Бренд-палитра @xtuned из video-design/brand.json — только акценты.
</референсы>

<тайминг>
0.0–4.0 send: страница уже оформлена (заголовок, @xtuned); прорисовываются ноутбук, сервер, телефон;
  в экране карточка «Привет!» и кнопка «Отправить»; курсор нажимает (2.9 с), карточка вздрагивает.
4.0–8.0 split: карточка поднимается над ноутбуком, ножницы режут её по границам «Пр|ив|ет|!»,
  куски расходятся и становятся заметками 1–4 с цветной штриховкой и кружками номеров; рисуются роутеры и связи.
8.0–11.5 route: заметки летят разными путями через роутеры, оставляя цветной пунктир; роутеры «мигают»;
  приходят 3, 1, 4, 2 в ряд под сервером.
11.5–12.5 think: на экране сервера крутится карандашный лоадер, «хм…», номера обводятся по порядку 1→4.
12.5–15.0 join: заметки меняются местами по дугам, съезжаются и сливаются в «Привет!», рисуется галочка,
  на телефоне друга появляется пузырь; с 14.2 спокойная пауза.
</тайминг>
