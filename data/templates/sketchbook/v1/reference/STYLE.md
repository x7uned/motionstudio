# «Карандашный скетчбук» · style-lab/sketch

## Идея
Ролик как страница тетради в клетку, на которой преподаватель от руки объясняет схему. Одна постоянная
картинка без перелистываний: ноутбук «ты» внизу, три маршрутизатора посередине, сервер и телефон «друг» вверху.
Всё прорисовывается карандашом (draw-on), штриховка заполняется «каракулями», подписи пишутся слева направо
и подчёркиваются жёлтым маркером. Сообщение «Привет!» — бумажная карточка: ножницы режут её по границам
«Пр | ив | ет | !», куски превращаются в цветные заметки-стикеры с кружками номеров 1–4, летят разными
путями, оставляя цветной пунктир, приходят 3, 1, 4, 2, сервер «думает» (карандашный лоадер, «хм…», номера
обводятся по порядку), заметки меняются местами по дугам и снова срастаются в карточку с галочкой;
на телефоне друга появляется пузырь «Привет!». Пауза с 14.2 с.

## Шрифты
Caveat 700 (и 400) из локального `@fontsource/caveat`, кириллица поддерживается. Рендер ждёт
`document.fonts.load()` через `delayRender`, затем canvas `measureText` измеряет префиксы слова — по ним
проходят линии разреза, и подписи масштабируются, чтобы влезть в 900 px.

## Библиотеки и детерминизм
- Rough.js 4.6 (`rough.generator()`, `opsToPath` → SVG-пути; контур и штриховка разделяются по типу набора).
  У каждой фигуры фиксированный `seed`; «кипение» линии — один из 3 seed, смена каждые 4 кадра
  (`base + (floor(frame/4) % 3) * 7919`), т.е. 7.5 fps, намеренно. Результаты кэшируются по ключу+seed.
- Draw-on: каждый под-путь с `pathLength=1`, `strokeDasharray="1 1"`, `strokeDashoffset=1-p`, со сдвигом
  по времени — контуры рисуются, штриховка «заскребается».
- Бумага и графит: SVG `feTurbulence` с фиксированным seed (зерно бумаги и маска зернистости штриха), радиальная виньетка.
- Всё — функции от `useCurrentFrame()`: никаких Math.random/Date/таймеров/CSS-анимаций. Маршруты — заранее
  посчитанные сплайны Catmull-Rom с длиной дуги. Проверка межкадровой разницы готового MP4: выбросов нет,
  максимумы приходятся на быстрое перемещение заметок (12.6–13.7 с); на паузе видно только мягкое кипение линий
  (средняя разница ~1.2/255 раз в 4 кадра).

## Что перенести в настоящие ролики студии
Как подготовленный рендерер (`renderer/SketchFilm.tsx`), управляемый проверенным JSON, без генерируемого кода:
- примитивы-«сборки»: `device` (laptop/server/phone/router), `note` (цвет, текст, номер), `card`, `label` со
  стрелкой, `route` (точки пути), `cut` (разрезы по префиксам текста), `check`, `loader`, `teaser` («?»-путь);
- таймлайн из меток слов озвучки (draw-on, полёт, обводка, слияние — на cue-кадрах);
- палитра из brand.json + 4 пастельных «носителя смысла», Caveat для рукописных подписей;
- субтитры как «надпись от руки с маркером» по группам слов.
Хорошо подходит для объяснения процессов и схем (сети, алгоритмы, очереди), где важен постоянный граф.

## Ограничения и что нужно для продакшена
- Caveat: «в» похожа на латинскую «b», куски слова рисуются отдельными text-узлами, поэтому в склеенном «Привет!»
  нет лигатурных соединений и заметен небольшой зазор между «в» и «е». Для продакшена — проверить другие
  рукописные шрифты с кириллицей или рисовать текст по глифам.
- Кипение затрагивает и серую штриховку инфраструктуры; если на большом экране это слишком живо — оставить
  штриховке фиксированный seed (только контуры «кипят») и/или выключать кипение в финальной паузе.
- Зерно `feTurbulence` на весь кадр повышает размер PNG (~4 МБ кадр) и время рендера; MP4 15 с ≈ 10.8 МБ.
- Геометрия схемы сейчас задана координатами под одну историю; нужен авто-лэйаут узлов/маршрутов из JSON
  и проверка безопасной зоны.
- Ролик немой; звук (шорох карандаша, ножницы, «бумажные» вуши) — по правилам sound-design отдельно.
