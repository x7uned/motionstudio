# Пиксель-фильм · v1

**Образец стиля. Рендерер ещё не подключён к конвейеру: проект по этому шаблону создать нельзя, пока стиль не реализован.**

32-битный пиксель-арт в палитре студии: сетка 540×960 ×2 без сглаживания, свои пиксельные шрифты, изометрические диорамы, вырастающие из пиксельной планеты (кафе → квартал → Земля), растворение дизерингом, 8-битные звуки и чиптюн. Эталон — «What happens when you tap» (58 с, голос Dennis).

Сохранён 2026-10-21 по просьбе пользователя: «Отлично. Теперь сгенерируй кавер-фото и сохрани этот шаблон, скорее даже как отдельный стиль. Ну, сохрани его под названием «Пиксель-фильм». И также сохрани, если там у нас есть какие-то примерные компонентов, то есть если нету, то создай, типа вот у нас сейчас теперь компоненты, можно создать первую землю, если нету еще. Если есть, то просто добавь туда эту землю, пиксель, она хорошо получилась, я хочу, чтобы ты ее дальше еще использовал.»

Эталон: 57.9-секундный ролик «What happens when you tap» с голосом Dennis (один дубль), 8-битными звуками и чиптюном (`reference/video.mp4`, кадры и контактный лист рядом; обложка и рабочая копия с данными — `work/pixel-lab/tap-film/`). Исходники образца на момент сохранения — `reference/source/`. Правила — наблюдения одного образца, не обучение модели.

## Известные недостатки образца

- Рендерер — отдельный скрипт на Node (work/pixel-lab/tap-film), не подключён к конвейеру студии: нет JSON-плана, режиссёра и проверок студии.
- Сцены (кафе, квартал Токио, Лондон) собраны под одну историю; для других тем нужны новые подготовленные диорамы.
- Берега Земли обведены вручную (~1°); маршрут по кабелям и узлы сети условные.
- Пиксельные шрифты пока без кириллицы: русские ролики потребуют новых глифов.
- Звук проверен измерениями и проигрыванием файла, на слух его оценивает пользователь.

Общие пиксельные компоненты (растр, шрифты, Земля v1) — `renderer/pixel/` (README там же). Описание стиля для агентов — `docs/pixel-film.md`.
