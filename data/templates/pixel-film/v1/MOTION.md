# Движение

- Весь кадр рисуется на сетке 540×960 и увеличивается ×2 без сглаживания; смешанные размеры пикселя запрещены, кроме аватара и плиток-логотипов в полном разрешении.
- Палитра студии с рампами фиолетового; жёлтый — маршрут и внимание, зелёный — одобрено, розовый — проблема; живые цвета только у флагов, логотипов и ориентиров (Токийская башня).
- Один постоянный мир: пиксельная планета, из которой непрерывным наездом вырастают изометрические диорамы мест; экраны не листаются.
- Камера идёт от близкого к общему: интерьер места → квартал вокруг него → планета; интерьер вписан в здание квартала в масштабе 1:2.
- Появления, исчезновения и смены состояния — растворение дизерингом Байера за 0,15–0,4 с; ни один объект, текст или цифра не меняется за один кадр.
- Маршрут — пунктир по земле или кабелю; пакет-конверт с замком едет по нему, пройденная часть светится; ответ возвращается зелёным пакетом.
- Шапка: аватар (лицо и верх тела) в полном разрешении, ник и длительность пиксельным шрифтом, заголовок MAIN ×3; субтитры-караоке MAIN ×3 на y≈1380.
- Метки мест — плашка с флагом (Wikimedia Commons) и названием; организации, которые звучат в тексте, — плитка с настоящим логотипом на слове.
- Масштаб события показывается приёмами игры: мини-терминал «WAITING», счётчик километров, сутки на глобусе, монеты по маршруту.
- Звук только 8-битный и тематический; каждый звук длится ровно столько, сколько его движение (наезд, полёт пакета, контакт карты).
- Заставка в той же сетке: вопрос, персонаж из спрайт-листа с растворением кадров, курсор, кнопка FOLLOW → FOLLOWING ✓, клик и арпеджио из пака.
- Обложка: плашка темы y300, двухстрочный пиксельный заголовок, сцена в 590–1490, аватар + ник + плашка одной строкой на y1545 (зона 3:4).

## Библиотеки и детерминизм

- Свой растр на Node (renderer/pixel/raster.mjs): сетка 540×960, увеличение ×2 nearest, примитивы, упорядоченный дизеринг Байера, fade()
- Пиксельная Земля renderer/pixel/earth.mjs v1: орфографическая проекция, день/ночь, огни городов, гладкие берега при любом наезде
- Изометрия 2:1 (iso.mjs/scenes.mjs): диорамы кафе, квартала Токио и ночного Лондона, масштаб U для непрерывного наезда
- sharp — спрайты и полноразмерные плитки (аватар, флаги, логотипы с Commons); ffmpeg rawvideo → H.264 yuv420p bt709
- 8-битный синтез (synth.mjs): пульс/треугольник/LFSR-шум, параметры шагами 60 Гц, громкость 4 бита; чиптюн-подложка с дакингом −12 дБ

Каждый кадр — чистая функция номера кадра: без Math.random, Date, таймеров и CSS-анимаций. Правила плавности video-design/MOTION-RULES.md: ничто не появляется и не исчезает за один кадр; одна постоянная система на весь ролик.
