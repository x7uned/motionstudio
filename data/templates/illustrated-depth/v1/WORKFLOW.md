# Как подключить стиль

1. Пользователь говорит, что этот стиль нужно реализовать.
2. Подготовленный рендерер на основе `reference/source/`, управляемый проверенным JSON (сборки, маршруты, тайминги по меткам слов) — без генерируемого кода.
3. Новая версия шаблона с connected:true и эталоном из одобренного ролика.
4. Дальше — обычный конвейер: исследование, рассказ, озвучка, постановка, рендер, ревью итогового MP4, одобрение пользователем.
