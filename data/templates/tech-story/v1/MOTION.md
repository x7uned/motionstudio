# Правила движения

Одна шкала времени: storyboard.json, alignment.json и кадр при 30 fps. Только чистые функции кадра. CSS transitions/keyframes, Date, случайность и таймеры в рендере запрещены.

Ничто видимое не появляется и не исчезает за один кадр. Общие объекты сохраняют идентичность между главами. Узлы расширяются, делятся, схлопываются в родителя; ветви раскрываются из уже видимой системы. Перелистывание страниц и сдвиг всего поля справа налево запрещены.

Точные длительности — settings.json. По эталону: плавный вход заголовка, быстрый выход; локальный callout проявляется вместе с небольшим ростом; архивный кадр масштабируется от 0,9 к 1 и затем медленно приближается не более 4,5%. Не двигать слова, пока их читают. Общая шапка не появляется заново на каждой главе.

Тексты в одной позиции меняются последовательно: сначала уходит старый, затем приходит новый. Не склеивать в одну нечитаемую надпись две даты или два заголовка. Фотографии могут мягко перекрываться. Если кадр остаётся в соседних главах, сохранять один слой и полную видимость на границе; не создавать провал непрозрачности.

Ключевой объект входит по конкретному слову фактической озвучки. Резервное смещение относительно начала главы допустимо только без подходящей метки. Не показывать ответ сильно раньше объяснения. Короткая фраза после появления держится не меньше секунды; финальный вывод — не меньше двух.

Субтитры мягко входят и выходят через маску; подсветка слова интерполируется. Не заменять строку жёстко в одном DOM-узле. Переход не должен закрывать важную часть диаграммы. Без пустого чёрного кадра между частями.

Рендерить закреплённым Remotion Chrome Headless Shell. Успешный код завершения не доказывает отсутствие мерцания. Проверять последовательные кадры и локальные временные выбросы, затем реальное воспроизведение.
