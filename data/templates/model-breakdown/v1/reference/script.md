# Эталонный текст · только Tesla

Как Tesla объясняет полёт Roadster? Tesla назвала демонстрацию нового Roadster полётом. По словам компании, воздух хранится в баллонах высокого давления, а машина может сама пополнять его запас. Проследим путь воздуха на условной схеме: из баллонов по магистралям, через клапаны — к соплам. Если сопла разгоняют газ вниз, реактивная сила толкает машину вверх. Горение для этого не требуется. Чтобы начать подъём из покоя, силы вверх должны в сумме перевесить силы вниз, включая тяжесть. Вентиляторы под днищем, по словам Tesla, решают другую задачу: усиливают прижим к поверхности. Физика объясняет механизм, но возможности именно этой машины требуют отдельной проверки. Хочешь узнать больше? Подписывайся на xtuned.
