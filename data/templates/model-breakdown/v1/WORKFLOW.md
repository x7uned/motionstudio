# Использование

1. Выбрать шаблон, тему и бюджет. По умолчанию60с9:16; финальная длительность определяется естественной речью. Снимок правил сохраняется в новом проекте, старый не меняется.
2. Исследовать тему и пройти редактуру/фактчекинг по текущим правилам. Явный выбор сценарного агента и режима проверки сохраняется.
3. Подготовить визуальную концепцию, подробную сборку/GLB и motion JSON через существующие роли. Для отсутствующего предмета подготовить модель до TTS; не заменять молча примитивом.
4. Для фирменной заставки скопировать assets/dennis-avatar.png в data/projects/<new-id>/branding/avatar.png, сверитьSHA и указать новый путь в creatorBranding. Привязать outro к последней сцене нового текста. Не оставлять scene-8 и ID/тайминги Tesla. Добавить реплику подписки до TTS и проверки. Эта подготовка пока не автоматизирована выбором шаблона.
5. Получить один Dennis-мастер, реальные метки слов и измеренный storyboard. Подготовить звук v8 по новым motion keys. Применить сохранённые вsettings.json уровни в новом cue sheet; совпадение настройки шаблона с глобальным миксом не предполагается. Использовать разрешённые локальные записи; если нужен Openverse — один поиск на тип, license=cc0,by,pdm и source=freesound,jamendo, curl вsfx, attribution без изменений вcredits.txt.
6. Render → проверка финальногоMP4 → один допустимый ремонт картинки без повторного TTS → новое ревью. Фон не меняется при ререндере.
7. Явное одобрение редактором. Само сохранение этого шаблона не одобряет автоматически новые видео.

Эталон и assets — read-only образцы. Не переносить их Tesla-факты, конкретные таймкоды и пути проекта в новые темы. Не перезапускать активную очередь ради установки шаблона.
