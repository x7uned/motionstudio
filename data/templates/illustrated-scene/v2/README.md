# Иллюстрированная сцена · v2

Сохранённый формат @xtuned по прямому решению пользователя (2026-10-19). Это v1 плюс фирменная обвязка: аватар @xtuned в шапке, голос Dennis и пиксельная заставка подписки в конце. Эталон — «Как один бит прибавил 4096 голосов», 102 с (проект `178dad90`), копия в `reference/` с SHA-256. v1 и его эталон про лавовые лампы не изменены; проекты v1 сохраняют свой снимок. Это производственная инструкция, а не обучение модели.

В студии выберите «Иллюстрированная сцена» (теперь v2). Новый проект получает 9:16, бюджет 60 с по умолчанию, 2D-рендер с фильмом `illustrated`, визуальную концепцию, случайный одобренный фон, голос Dennis · eleven_v4, снимок аватара `assets/avatar.png` (в шапку) и снимок заставки `xtuned-outro/v1`. После измеренной озвучки режиссёр Claude Opus 5.5/xhigh ставит один мир из предметов каталога (`docs/illustrated-renderer.md`). Выбор сценарного агента и мягкого фактчекинга остаётся явным выбором редактора.

DESIGN — композиция и шапка; CONTENT — рассказ; MOTION — постановка, заставка и звук; VOICE — речь; WORKFLOW — порядок работы; CHECKLIST — готовность. settings.json — точные параметры, brand.json — палитра и аватар.

Границы: каталог предметов ограничен (лампы, камера, монитор, сервер, кадр-пиксели, хэш-пресс, смеситель, зерно, генератор, поток чисел, ключ, браузер, замок, табличка, вывеска, человек, космическая частица, микросхема памяти, кабина голосования, урна-считыватель, табло итогов). Для темы, которой не хватает предметов, сначала нужен новый предмет в рендерере — шаблон не рисует его сам. Голос Dennis v4 берёт не больше 2000 знаков за один непрерывный дубль: это около 2 минут речи вместе с заставкой. Эталоны и их факты в новые темы не переносятся.
