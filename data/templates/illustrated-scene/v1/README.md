# Иллюстрированная сцена · v1

Сохранённый формат @xtuned по прямому решению пользователя. Эталон — «Как хаос лавовых ламп превращается в ключи», 48 с (проект `216eeb4d`), копия в `reference/` с SHA-256. Это производственная инструкция, а не обучение модели.

В студии выберите «Иллюстрированная сцена · v1». Новый проект получает 9:16, бюджет 60 с, 2D-рендер с фильмом `illustrated`, визуальную концепцию, случайный одобренный фон и снимок этих инструкций. После измеренной озвучки режиссёр Claude Opus 5.5/xhigh ставит один мир из предметов каталога (`docs/illustrated-renderer.md`). Выбор сценарного агента и мягкого фактчекинга остаётся явным выбором редактора.

DESIGN — композиция; CONTENT — рассказ; MOTION — постановка и звук; VOICE — речь; WORKFLOW — порядок работы; CHECKLIST — готовность. settings.json — точные параметры, brand.json — палитра.

Границы: каталог предметов ограничен (лампы, камера, монитор, сервер, кадр-пиксели, хэш-пресс, смеситель, зерно, генератор, поток чисел, ключ, браузер, замок, табличка, вывеска, человек). Для темы, которой не хватает предметов, сначала нужен новый предмет в рендерере — шаблон не рисует его сам. Эталон и его факты в новые темы не переносятся.
