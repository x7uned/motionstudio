# Заставка @xtuned · xtuned-outro/v1

Общая концовка для новых роликов любого типа (explainer, 3D, netcode, illustrated). Решения автора от 2026-10-19:

- Голос — **последняя фиксированная фраза общего текста**, в одном непрерывном TTS-дубле с роликом. Фразу дописывает пайплайн, а не сценарист; редактура и фактчекинг её не переписывают.
  - RU: «Хочешь больше таких разборов? Подписывайся на xtuned.» · кнопка «Подписаться» → «Вы подписаны ✓».
  - EN: «Want more breakdowns like this? Follow xtuned.» · кнопка «Follow» → «Following ✓» (Instagram Reels).
- Под фразу резервируется `reserveSeconds` из бюджета; после слова «xtuned» остаётся хвост `tailSeconds` для нажатия и отклика. Пауза перед фразой естественная, без вставки тишины.
- Персонаж — `denis-story/v1` (копия `spritesheet.png`, SHA-256 в `outro.json`): приветствие → указывает на кнопку на слове «Подписывайся»/«Follow» → радуется после нажатия.
- Смены кадров спрайта и поз — перетекание за 2–3 кадра / 0,3 с; ничего не появляется и не исчезает за один кадр.
- Кнопка своя, пиксельная, в цветах бренда (#8D59DA → #65DA41), не копия интерфейса Instagram. Текст в safe-zone Reels.
- Звук: утверждённый мягкий whoosh на входе; клик с начала нажатия после «xtuned»; арпеджио на переключении кнопки. Кандидаты — `data/sound-packs/outro-8bit-01`. Пока редактор не выбрал, `sounds.click/success = null` и заставка звучит только whoosh.
- Бренд в фразе проверяется по ASR (`brandHeard`): если «xtuned» не распознан, технический пасс не проходит.

Новые проекты снимают копию пака в `data/projects/<id>/branding/xtuned-outro-v1/` и SHA-256 в `profile.creatorOutro`. Старые проекты, Tesla (creatorBranding v1) и tech-story/v1 не меняются. Новая версия заставки — отдельная папка `v2`, эту не переписывать после выпуска роликов.
