# Стиль «Стикмен» · наблюдения по одному референсу

Источник: «Work smart over hard.mp4» (Telegram, копия `reference/source.mp4`,
SHA-256 `e6baa49ac77af2d88f94e81cbdd180b9953c14f7cd2cd6cd1cd428cdc24f7760`).
Это наблюдения по одному ролику, а не обучение модели. Кадры: `reference/frames` (2 кадра/с),
листы `reference/sheet1-3.jpg`.

## Про что ролик
Мотивационный ролик без голоса, 33,6 с, 720×1280, 30 fps. Семь коротких сцен по 3–6 с, каждая —
одна мысль про успех, показанная одной визуальной метафорой со стикменом. Почти везде сравнение «плохо → хорошо»:

1. «Working Hard / Working Smart» — один бьёт рыбу копьём, второй сидит в шезлонге с удочками.
2. «Multitasking / Focused» — шарик прыгает по пяти столбикам (все низкие) против одного столбика, который растёт вверх.
3. «"Lucky"» — внизу человек, наверху человек с золотым кубком; камера отъезжает: «The Luck:» — длинная лестница, по которой тот поднимался.
4. «Today / In a month / In a year» — человек толкает куб, потом скруглённый куб, потом шар (усилие становится лёгким).
5. «SUCCESS / The First Step Is Always The Hardest / Break It Into Smaller Steps» — две шахты с лестницей; одному не допрыгнуть, второй дорисовывает себе мелкие ступеньки.
6. «If you knew you had to fail 100 times… How fast would you want to fail?» — человек прыгает с блока на блок: красный FAIL, потом зелёный WIN, столбик растёт до SUCCESS.

Звук: только громкая музыка (средний уровень −6,6 dB), смена характера/дроп около 16 с, голоса нет.
Весь смысл несёт короткий текст на экране.

## Картинка
- Фон чисто чёрный. Почти всё чёрно-белое: белые фигуры, серые линии земли/ступеней (~#6E6E6E, толщина ~8 px при 720).
- Цвет — только у объекта-акцента и его слова: золотой кубок и «SUCCESS», красный блок и «FAIL», зелёный блок и «WIN».
  Один цвет на сцену, цвет слова = цвет объекта.
- Два режима освещения:
  - плоский — белые векторные фигуры без теней (сцены 3, 6);
  - «свечение» — мягкий белый ореол вокруг фигур, градиентная заливка конечностей (объём «пилюлей»),
    светлое пятно на земле, серые объёмные камни/рыбы (сцены 1, 4, 5). Ключевое слово светится (SUCCESS с bloom).
- Мир — минимум линий: пол, ступень, столбик, лестница. Никаких текстур и фоновых деталей.

## Стикмен
- Голова — отдельный белый круг с маленьким зазором до туловища.
- Туловище — толстая капсула со скруглёнными концами; руки/ноги — капсулы потоньше, по два сегмента
  (плечо–локоть–кисть, бедро–колено–стопа). Ступней и кистей нет, концы круглые.
- Наложение конечностей читается по тонкой тёмной линии-разделителю; дальние руку/ногу можно слегка затемнить.
- Движение простое: шаг, толчок, прыжок, подъём рук. Наклон корпуса показывает усилие.

## Текст
- Геометрический гротеск (похож на Montserrat), белый, небольшой, по центру сверху или подпись над объектом.
- Появляется по словам/буквам мягким проявлением, старые строки остаются, новые добавляются ниже.
- Подписи-ярлыки в кавычках («"Lucky"»), заголовки с двоеточием («The Luck:»).
- Внизу полупрозрачный водяной знак автора — у нас его нет (правило «без оверлея»).

## Монтаж и камера
- Камера почти всегда стоит; один приём — отъезд, открывающий скрытый масштаб (лестница «удачи»).
- Сцены сменяются через затемнение в чёрный. Внутри сцены — циклы (рыбы, шарик, шаги) до смены.

## Наши правила для превью (поверх наблюдений)
- 1080×1920, 30 fps, картинка на весь кадр, без аватара/хэндла; важное в безопасной зоне (docs/safe-zones.md).
- Ничего не появляется и не исчезает за один кадр; герой в кадре с первого кадра и уже движется.
- Локальный шрифт Manrope (Montserrat в проекте нет). Свой сюжет, не копия сцен референса.

## Сцена 2 · «Алмаз в шахте» (10 с)
Земля в разрезе: копёр, шахта с лестницей, два туннеля по сетке блоков 60 px. Шахтёры в касках с фонарями
(луч света — часть освещения), обводок нет. Удары: трещины → блок рассыпается камешками → шаг вперёд.
Верхний сдаётся (роняет кирку, разворачивается, уходит); камера наезжает, алмаз «просвечивает» через последний
блок (пунктир). Нижний пробивает, алмаз вылетает в руки, голубая вспышка. Свет-прожектор приглушает нижний
туннель, пока камера смотрит наверх. Код: `renderer/style-lab/stickman-mine/index.tsx`.

Сцены: машина 47 раз заезжает на U-образный трек (TEST 01…46 FAIL — разбивается в дыму, TEST 47 PASS —

### Как нарисованы объекты (кроме стикмена)
- Объект — серый, не белый: белый остаётся у героя. Объём по тону: светлая верхняя грань → средний бок →
  тёмный низ (вертикальный градиент), тонкая светлая кромка по верхнему контуру вместо обводки.
- Машина — строгий профиль сбоку, плоские панели: светлый кузов, тёмное стекло, тёмная боковая вставка,
  колёса = тёмная шина + тонкое светлое кольцо диска + лопасти-«турбина» + точка ступицы. Под ней зеркальное
  отражение на глянцевом чёрном полу, быстро гаснущее вниз. Свет фар — пятно-свечение и мягкий конус.
- Конструкции (трек, ферма) — светлая объёмная лента с полосами разметки + тонкая серая ферма из треугольников.
- Холм/постамент — тёмная заливка с градиентом и мелким зерном, тонкая светлая линия по краю; ступени — серый контур.
- Кубок — металлический серый с бликом на тёмном постаменте. Скамейка — тёмные доски с тонкими светлыми рёбрами.
- Сарай — светлые доски с точками-гвоздями, мягкий объём, двускатная крыша; почти фронтальная проекция.
- Иконки мыслей — линейные пиктограммы внутри облачка с цепочкой кружков; облачко-мечта и цель — жёлтый контур.
- Второстепенные фигуры уходят в серый (#555–#777), а не исчезают; цвет-акцент — один на сцену (красный FAIL,
  зелёные флажки и свечение, жёлтая мечта).
- Текст двух типов: разреженный техно-капс (EVERYONE SAW THE SUCCESS, TEST 47, PASS в рамке) и жирный
  гротеск капсом. У нас по решению пользователя — Prata.

### Дымка и дым
- Дым: плотное белое тело, лежит на земле; верхний край бугристый (кучевые клубы), плотность падает вверх и
  назад; объект в дыму виден силуэтом, низ колёс скрыт.
- Потом дым расходится в большую мягкую серую «дымку» — купол светлого тумана на весь кадр, сцена в нём
  чуть приглушена, свет фар даёт яркое пятно.
- Наш приём (детерминированно, без видео): тело облака — ряд крупных кругов с плотным радиальным градиентом;
  бугры — круги поменьше по верхней кромке; оба слоя через `feTurbulence` (fractalNoise, ~0,02) +
  `feDisplacementMap` (~45) + лёгкий blur 3–4 px; ореол — те же круги с blur ~34 и прозрачностью 0,55;
  редкие клочья сверху — blur ~70, прозрачность ~0,2; купол дымки — большой радиальный серый эллипс;
  облако обрезано по линии пола и отражено в нём. Часть клубов кладётся перед объектом.
