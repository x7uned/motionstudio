# Бриф · «Акварель и маркер»

<задача>
Один 15-секундный образец стиля для Motion Studio (1080×1920, 30 fps, 450 кадров, без звука) на общий сюжет `work/style-lab/story.json` «Как сообщение доходит до друга»: ноутбук отправляет «Привет!» → карточка режется на 4 пакета с номерами и кусочками «Пр», «ив», «ет», «!» → пакеты идут через 3 маршрутизатора разными путями и приходят в порядке 3, 1, 4, 2 → сервер «думает» → пакеты встают 1–4 и сливаются обратно в «Привет!» с галочкой, спокойная пауза ~0.8 с.
Подписи бита — дословно из story.json, по таймингу битов. Ключевой текст в безопасной зоне (≥220 px сверху, ≥320 px снизу, x 78..1002). Маленький «@xtuned» ненавязчиво.
Правило движения: ни один объект/текст/состояние не появляется и не исчезает за один кадр — всё раскрывается, уходит и меняет состояние непрерывно.
</задача>

<стиль>
Иллюстрация детской книги / журнальная иллюстрация: мягкие акварельные заливки с растекающимися краями, контуры маркером/тушью с фактурой, штриховка карандашом/углём в тенях, тёплая хлопковая бумага с зерном.
Палитра — приглушённая акварель на тёплой бумаге: индиго, терракота, шалфей, горчица, роза; один цвет туши для всех контуров.
Шрифты: подписи — Manrope (variable, локальный @fontsource), рукописные пометки — Caveat. Текст чёткий, в HTML/Canvas 2D, не кистью.
Библиотека: p5.brush 2.x поверх p5 2.x (instance mode, WEBGL), кисти fill (акварель), hatch, set("marker"/"pen"/"2B"/"charcoal").
</стиль>

<референсы>
Наблюдаемые приёмы жанра (не обучение модели): акварельная заливка, чуть выходящая за чернильный контур (смещение пятна относительно линии); неравномерная плотность пигмента и тёмная кромка по краю пятна; лёгкая карандашная штриховка вместо мягких цифровых теней; бумага видна сквозь краску; «ручные» пунктирные траектории маркером.
Бренд @xtuned: ник сохраняется, палитра образца — отдельная экспериментальная (акварельная), а не замена брендовой.
</референсы>

<тайминг>
0.0–4.0 «Ты нажал «Отправить»»: бумага и рамка уже на месте; ноутбук раскрывается 0.1–0.6 с, сервер друга 0.5–1.1 с, карточка «Привет!» на экране 0.7–1.2 с, кнопка «Отправить» 1.1–1.5 с; курсор подлетает 1.5–2.4 с, нажатие 2.6 с, карточка вздрагивает 2.65–3.3 с, курсор уходит, карточка поднимается над ноутбуком 3.3–4.2 с.
4.0–8.0 «Сообщение режется на пакеты»: пунктир разреза прорисовывается 4.4–5.2 с, части расходятся 5.3–6.3 с с перетеканием цвета в цвета пакетов, номера 1–4 раскрываются 6.0–6.9 с, маршрутизаторы и карандашные «провода» сети раскрываются 6.6–7.8 с.
8.0–11.5 «Каждый пакет ищет свой путь»: старт 8.05/8.2/8.35/8.5 с, каждый пакет оставляет маркерный след своего цвета, маршрутизаторы пульсируют при проходе; прибытие в лоток у сервера: 3 (9.7 с), 1 (10.2 с), 4 (10.7 с), 2 (11.25 с).
11.5–12.5 «Сервер проверяет номера»: орб над сервером дышит, точки кружат, номера подсвечиваются по очереди.
12.5–15.0 «И собирает их по номерам»: перестановка дугами 12.5–13.2 с, сближение 13.2–13.7 с, слияние в «Привет!» 13.5–14.0 с, галочка 13.8–14.25 с, спокойная пауза 14.2–15.0 с.
Подписи: выход старой и вход новой одновременно, 0.2 с, сдвиг за маской.
</тайминг>
