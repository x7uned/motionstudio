## Что добавлено в общий набор «казино»
Замороженная копия набора из `casino-money/film` + новый `casino-games.mjs` (API в шапке файла). В `casino.mjs` (копии) два маленьких хука: `o.back` (рисуется сразу после пола и стены — для потолка) и `o.walkerMaxZ` (убрать прохожих из нашего прохода). В `render.mjs` полигоны обрезаются по холсту (вершина у самого объектива не стоит миллионов пустых строк).
- `bjTable` — стол блэкджека (полумесяц, дуга, 5 мест, лоток крупье с подсветкой, шуз, сброс), `bigCard` — карты крупнее жизни, ранг и большая масть рисуются прямо на экране (читаются на телефоне), переворот через сжатие, красный оттенок при переборе.
- `placard` — стоячая табличка стола (поднимается из сукна), `lastBoard` — высокое табло последних чисел на латунной стойке (новое сверху, красные слева, чёрные справа, подсветка, гаснет).
- `crapsTable` — стол для костей (ванна, ромбы на дальней стенке, PASS LINE, поле, центр, фишки), с отсечением по ближней плоскости камеры (`clipProj`).
- `die3D` — прозрачный красный кубик в любой ориентации, по пикселям: сквозь грани видно сукно и точки дальних граней, острые рёбра с бегущим бликом, «No 0427» на грани 1, режим «спокойное лицо» на грани 2, непрозрачный «чужой» кубик.
- `ceilingPass` — тёмный кессонный потолок по пикселям, светильники, купола камер (дымчатое стекло, объектив поворачивается к цели, красный огонёк), `DOME_SPOTS`.
- `palm` — большая открытая ладонь (ладонь / тыльная сторона, поворот), `stamp` (повёрнутый штамп), `badge`, `plate`, `bubble`.
