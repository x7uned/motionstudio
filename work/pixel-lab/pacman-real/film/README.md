## Спрайты (новые, `assets/sprites.mjs`)
- Рисуются из ручных строковых сеток, без дуг и эллипсов. Плоские цвета, клетка — точный квадрат N × N, без обводки и сглаживания. Целый масштаб N на план; смена N — растворение всего кадра дизером за 0,3 с.
- **Пакман: тело 13 × 13 клеток, слот шириной 15.**
  - кадры wide, half, shut вправо; влево — зеркало, вверх и вниз — поворот на 90°;
  - кадр «gulp» 15 × 11.
  - Ширина тела по факту — 13 клеток, точка — 2 × 2. Фразы «about 13 pixels» и «2 pixels» совпадают с нашим рисунком по построению. 13 px оригинального спрайта по-прежнему не подтверждены первоисточником, поэтому в тексте «about».
- **Рот** меняется в игровом темпе, кадр каждые 2 видеокадра. Первый кадр нового положения — 50 % клеточный дизер. В замедлении темп снижается вместе со временем.
- **Поворот и «глоток»** — байеровское растворение по клеткам за 2–3 кадра.
- **Призраки 14 × 14:**
  - две юбки, глаза вправо, влево, вверх, вниз;
  - злые глаза Блинки;
  - испуганные синие с двумя юбками и белым миганием, только глаза.
  - Цвета: Блинки красный, Пинки розовый, Инки голубой, Клайд оранжевый.
- **Тень** — плоская полоса в одну клетку с дизерными концами.
- **Масштабы:** лабиринт N 14; улица N 18; весы N 10; погоня N 16; сверху N 8; окна игры N 8 и N 4; силуэт N 5.
