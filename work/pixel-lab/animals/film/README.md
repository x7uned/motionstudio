# «From the dumbest animal to the smartest» · пиксельный ролик, петля (2026-10-23)

- **Аккаунт:** Kagenami. English, Dennis · Eleven v4, один дубль (`narration.txt`, 238 слов).
- **Формат:** 1080×1920, 30 fps, 75,867 с (2 276 кадров). Без оверлея: картинка на весь кадр, только субтитры на мягкой тени.
- **Стиль:** милые пиксельные животные смотрят в камеру, как чёрная кошка с фото пользователя (`dev/cat-test.png`). Один мир боком: морской столб → берег → луг → двор → лес → бухта → саванна → джунгли → ночной город → нырок в гавань = первый кадр. За головой каждого животного одно и то же светило: свечение в глубине → солнце → закат → луна.
- **Порядок:** губка, медуза, осьминог, пчела, собака, ворона, дельфин, слон, шимпанзе, человек. Осьминог и пчела поменяны местами по решению пользователя.

## Устройство

- `timeline.mjs` — слова, уровни, события, камера, END.
- `world.mjs` — небо, вода, светило по положению камеры.
- `cute.mjs` — набор для милых животных: объём, контур, глаза, румянец, таблички, подборы.
- `hero.mjs` — герой в пуховике.
- `levels/*.mjs` — уровни. Их строили помощники по `BRIEF.md`; город и нырок — `levels/city.mjs`.
- `levels/*-motions.mjs` — времена движений. Из них `cues.mjs` и `synth.mjs` делают 8-битные звуки длиной ровно в движение. Подложка C–G–Am–F: 9 полных циклов, 113,9 BPM, через стык без затухания.
- `mix.mjs` — голос −16 LUFS, подложка уходит на −12 дБ под речью.
- `cover.mjs` — обложка из кадров самого ролика.
- `../qa.mjs` — проверка MP4.
