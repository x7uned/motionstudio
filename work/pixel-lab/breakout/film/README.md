## Что построено
- Один мир: наш аркадный автомат в тёмном зале (без марок и надписей на корпусе): подсвеченный маркиз с абстрактной стеной кирпичей, большой чёрно-белый кинескоп (скруглённое стекло, строки развёртки, блик, затемнение краёв), сбоку декор из четырёх цветов, панель с ручкой-«крутилкой» (поворачивается вместе с ракеткой), кнопка подачи, монетная дверца.
- На трубке весь ролик одна игра — **симуляция по правилам руководства 1976 года** (`sim.mjs`, чистая функция времени): 8×14 кирпичей, очки 7/7/5/5/3/3/1/1, кирпич убирается и разворачивает мяч, 4 части ракетки → 4 фиксированных направления, скорости SLOW → 2 (4-й удар) → 3 (12-й) → TOP (первый оранжевый/красный), прорыв сжимает ракетку вдвое (плавно, 0,3 с), новая подача возвращает полную ракетку и SLOW. `dev/search.mjs` подбирает начальное состояние и план частей ракетки так, чтобы настоящие события легли на слова (`game-params.json`), `game.mjs` переводит всё во время фильма.
- По словам: кадр 0 — мяч летит, ракетка отбивает его на 0,2 с, в стене уже тоннель через все ряды; на «cut in half» над серединой ракетки мигает пунктир разреза; мяч уходит в тоннель и бьётся о верхнюю стенку на 6,86 с («top wall»), ракетка сжимается, «1/2»; мяч 1,3 с скачет между стенкой и красным рядом и ест красные кирпичи (настоящая механика прорыва), потом проваливается, ракетка не успевает — мяч потерян на 9,84 с («lose that ball»). Подача 2 (10,74 с): BALL 2, HITS 00, ракетка плавно растёт обратно, стрелка на SLOW. Спидометр (горел тускло с начала) загорается на «speeds up»; удары 1–4 идут в реальном времени, 4-й — на «fourth» (15,75 с, стрелка → 2); удары 5–12 — перемотка «>> FAST» (до ×12,8), 12-й — на «twelfth» (17,15 с, → 3); первый оранжевый кирпич на 19,59 с («brick») — стрелка сразу на TOP, «ORANGE / RED = TOP SPEED»; второй прорыв на 23,85 с — «FASTEST BALL» + «SMALLEST PADDLE», «1/2». «4 PARTS» — карточка: большая ракетка делится на 4 цветные части со стрелками, два мяча под разными углами попадают в одну часть и уходят одинаково («SAME WAY»). «Colors were fake» — четыре полосы съезжают со стекла (сдвиг + дизеринг), под ними белые кирпичи, затем возвращаются, «PLASTIC STRIPS». «Clear the wall» — перемотка: стена тает по кирпичу, счёт → 448, сверху вниз проявляется вторая стена («WALL 2»), тает → 896; мяч возвращается на пустое поле; «896» крупно + «MAX».
- Концовка (не петля): на «Follow» карточка FOLLOW → FOLLOWING ✓ (кнопочная часть deadliest/film/levels/cta.mjs через claw-machine/film/cta.mjs, без LIKED IT/SEND) выезжает поверх пустого поля под «896 MAX» (x 106–374, y 470–574), колокольчик на «miss», «MORE ARCADE SECRETS»; мяч продолжает прыгать. Удержание 0,88 с после голоса, музыка — каденция E7 → ля мажор с затуханием.
- Харнесс скопирован и заморожен из `claw-machine/film`: render/captions, mix, synth-core, sheet, cover, cta, cute, tts.py, dev/qa.mjs, dev/pops.mjs. Новые файлы: timeline, sim, game, cabinet, screen, overlays, synth, dev/search.mjs.

## Известные мелочи
- Мяч маленький (6 пикселей сетки = 12 px на 1080), как в оригинале; помогает след, который растёт со скоростью.
- Перемотка ударов 5–12 быстрая (до ×12,8, 1,4 с на 8 ударов): мяч там — светящийся зигзаг, рассказ держат счётчик HITS и стрелка. Иначе по таймингу дубля не уложиться.
- Во второй подаче после прорыва мяч сразу вылетает через проём (без долгого «дребезга»), долгий дребезг показан в первой подаче.
- К «Clear the wall» живой игрой разбито ~2/3 стены (44 кирпича из 112 остаются); тают они уже в перемотке.
- Нижняя треть кадра (панель управления под субтитрами) — фон по safe zones, там только ручка, кнопка и дверца.
- Скорости и углы мяча — условные (в руководстве только их число). Подписи — общий харнесс: группа гаснет за 0,29 с до следующей.
