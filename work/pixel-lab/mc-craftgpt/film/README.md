# «A chatbot built inside Minecraft» · пиксельный ролик про CraftGPT, петля (2026-10-25)

- **Аккаунт:** Kagenami. **Голос:** English, Dennis · Eleven v4, Plain English, один дубль (66,56 с, 203 слова).
- **Заказ:** «сделай мне видос по 1, то есть внутри Minecraft построили чат-бота с ИИ, реализуй такой видос в таком дизайне, как мы реализовали видос про Redstone» (идея №1 из `../../IDEAS-3-2026-10-25.md`). Продолжение ролика `mc-redstone` (323 тыс. просмотров за 8 часов).
- **Формат:** 1080×1920, 30 fps, 66,67 с (2 000 кадров). Без оверлея: картинка до краёв, субтитры караоке на мягкой дизеринговой тени. Безопасные зоны v1: все плашки в x 72–1008 / 72–880, y ≥ 312.
- **Сценарий и источники:** `../script.md` v1, `credits.txt`.
- **Концовка — петля.** «…So type your question, press enter, and wait, because» → «this chatbot is built inside Minecraft, and one answer takes two hours.» Пауза на стыке ≈0,2 с (внутри одной фразы). Камера садится в первый общий план, экран снова показывает вопрос и ждущего бота.

## Мир

Один блочный мир на весь ролик (воксельный движок ролика про редстоун, своя копия):
- `world.mjs` — суперплоская равнина; шесть залов-слоёв (фасады в ряд на z = −40, номера 1–6 из ламп, длина 1 656 блоков, в регион попадает видимая часть); крыши — ROM: «1» — блок стоит, «0» — нет; дорожки пыли с импульсами и факелы на крышах; экран из ламп 112×42; клавиатура из клавиш 2×2; панель на 240 ламп; модуль выбора токена; шина из пыли по площади. Дальность прорисовки 32 чанка (512 блоков) от героя: дальше — туман по чанкам.
- `voxel.mjs` — изометрический рейкастер + клавиши (KEY / KEY_ON) и туман по чанкам.
- `redstone.mjs` — пыль, факелы; дорожки на крышах залов идут вдоль зала.
- `scene.mjs` — состояние экрана (вопрос, рамки токенов, ответ по токенам, точки, полоса прогресса, полоса из 64 ячеек) со сменой каждого пикселя-лампы своим порогом; путь токена по проводам; лампы залов, панели, выбора; ROM-ряд, который строится на реплике; герой; камера.
- `screen.mjs` — шрифт 3×5 и раскладка экрана.

## Звук

8-битный синтез (`synth.mjs`), каждый звук длится своё движение: щелчки клавиш (пока клавиша нажата), Enter, смены экрана (0,35 с, как сама смена), печать токенов, точки «думает», гул сигнала по проводам (пока бежит), нота каждого слоя (пока он работает), заполнение панели, кандидаты и выбор, постановка блоков ROM, биты, тиканье 20 точек, гонг «10 лет», ускорение «×40 000», звон «2 часа», «вау-вау» бессмыслицы, свипы камеры, ветер в тумане. Подложка C–Am–F–G: 8 полных циклов, 115,2 BPM, без затуханий, −12 дБ под речью.
