# «Infinite aura» · полный брейнрот-ролик для канала друга (2026-10-25)

Полная версия теста `../../aura-stairs`, в стиле разобранного референса (`../REFERENCE.md`), с кринж-лестницей пользователя: голуби с лазерами, динозавры, метеориты, взрывы и т. д.

- **Формат:** 1080×1920, 30 fps, 38,27 с (1 148 кадров). Пиксельная сетка 540×960 ×2, без оверлея, караоке-субтитры как в наших пиксельных фильмах.
- **Голос:** один дубль Dennis · Eleven v4 [excited], 85 слов, 34 с. Scribe распознал текст слово в слово. Текст — `narration.txt`.
- **Музыка:** фонк пользователя из TikTok, `music/source.mp3`, sha256 `82e34340…`. Права неизвестны, загрузка на площадки — на усмотрение пользователя. Трек смонтирован под голос (`music.mjs`):
  - с 15,19 с трека — нарастание, первый дроп на «Ten thousand aura» (8,82);
  - на «Time» (25,68) трек останавливается, как плёнка;
  - хвост брейка трека;
  - второй дроп на «One billion» (27,62);
  - четыре такта до конца.
- **Звуковые эффекты:** четыре — рёв тираннозавра, большой бум на «explodes», «вуум» остановки времени, звон на «Infinite aura». На шаги, лазеры и метеориты звуков нет.

- **Ведущий:** герой и аура (из теста), мир (небо, облака, острова, лестница), счётчик STEP / число / AURA / строка «разблокировано», камера, остановка времени, вспышки, субтитры, монтаж музыки, звук, микс.
- **Помощник C:** `pigeons.mjs`, `dinos.mjs`, `moonface.mjs`, `ufo.mjs`.
- **Помощник X:** `meteors.mjs`, `explosions.mjs`, `space.mjs` (пиксельная Земля v1), `cta.mjs` (финальная карточка).
