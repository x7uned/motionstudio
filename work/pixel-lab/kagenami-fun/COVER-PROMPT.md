# Промпт: обложки для @kagenami_fun

Обложки собираются так же, как наши пиксельные: текст и строка канала — кодом, сцена — кадр из самого ролика. Эталон: `work/pixel-lab/aura-full/film/cover.png`, скрипт `cover.mjs` в той же папке.

- **Часть 1** — правила для того, кто собирает обложку: человек, скрипт или агент.
- **Часть 2** — промпт для модели, которая придумывает тексты и выбирает кадр.
- **Часть 3** — промпт для генератора картинок. Нужен, только если сцену рисует нейросеть, а не берётся кадр из ролика.

---

## Часть 1. Как устроена обложка

### Канал
- **Ник:** `@kagenami_fun` — в обложке заглавными: `@KAGENAMI_FUN`.
- **Аватар:** `work/pixel-lab/kagenami-fun/avatar.png`, 640×640.
  - На нём пиксельный парень с растрёпанными каштановыми волосами, в чёрных очках со спиралями и в салатовой футболке, с розовым кулоном-мозгом на шее, руки скрещены, он ухмыляется.
  - Фон аватара — розово-фиолетовые лучи.
  - Аватар не перерисовывать и не менять: только круглая обрезка.
- **Чего на обложке нет:** нашего @kagenami_ai, других ников, логотипов, реальных людей.

### Размер и поля
Instagram в сетке профиля показывает обрезку 3:4, то есть полосу y 240–1680 из 1080×1920. Всё нужное лежит внутри неё.

Картинка 1080×1920. Рисуем на сетке 540×960 и увеличиваем ×2 без сглаживания (nearest). Фон чёрный `#000000`.

| Элемент | Где (полное разрешение) | Как |
|---|---|---|
| Плашка-кикер | y ≈ 300, по центру | Рамка со скруглением 2, обводка фиолетовая `#8D59DA`, внутри тёмная `#120C1D`. Текст лавандовый `#E0CDF8`, пиксельный шрифт 5×7, масштаб 2 (на сетке). |
| Заголовок | y ≈ 384–560, две строки по центру, не ниже y 590 | Пиксельный шрифт 5×7, масштаб 6 (5, если строка длинная). Тень `#3B2C5C` со сдвигом 2. Строка 1 слоновая кость `#FDFEED`, строка 2 жёлтая `#F4CA50`. Не больше ~13 символов в строке. |
| Сцена | y 590–1490 | Кадр из ролика без счётчика, субтитров и затемнения под субтитрами (`frame(t, { clean: true })`). Срез 900 px по высоте, где видно главное. Верх и низ полосы растворяются в чёрный дизерингом Байера (≈ 70 px сверху, 60 px снизу). |
| Строка канала | y ≈ 1545, одной строкой по центру | Аватар-кружок 76 px (белое кольцо 1 px и розовое `#FF4FD8` по краю), отступ 20 px, `@KAGENAMI_FUN` масштаб 2 цвета `#FDFEED`, отступ 24 px, плашка-фишка (рамка и текст `#FF5A6A`, внутри `#120C1D`). |

Ниже y 1600 и выше y 260 ничего важного нет: там только чёрный фон.

### Тексты
- **Кикер.** Первая половина правила ролика, 3–4 слова: `EVERY STEP YOU TAKE`, `EVERY TIME YOU BLINK`.
- **Заголовок.** Две строки, вторая — развязка правила: `YOUR AURA / GOES UP`, `YOUR IQ / DOUBLES`. Для страшилок — завязка: `LAST PERSON / ALIVE`.
- **Фишка.** Самый кринжовый или самый страшный момент ролика, 2–4 слова: `PIGEONS HAVE LASERS`, `IT'S JUST A MOUSE…`, `DINOSAURS WOKE UP`.
- **Ограничения:** только заглавные латинские буквы, цифры и знаки `@ _ . , ' ! ? - : / + % ° · > < * ✓ $`. Символов `=`, `#`, `∞` в шрифте нет: ∞ рисуется отдельно, «=» и «#» не используем.
- **Слова** берём из озвучки или близко к ней. Не врём о содержании ролика.

### Кадр для сцены
- Самый насыщенный и смешной момент, где видно сразу несколько событий и героя. Для «Infinite aura» это 23,7 с: аура, голуби с лазерами, тираннозавр, луна с глазами, инопланетянин с «AUTOGRAPH?», взрыв.
- Лицо героя и главный «прикол» — в верхних двух третях полосы. Ничего важного не режется краем полосы.
- Для страшилки — момент напряжения, а не разгадка. Например, женщина у костра от первого лица или глаза в лесу. Не спойлерим финал полностью.

### Проверка
- [ ] Обрезка 3:4 (y 240–1680) показывает кикер, заголовок, сцену и строку канала целиком.
- [ ] Текст читается на превью шириной 200 px.
- [ ] В сцене нет счётчика, субтитров и чёрных полос.
- [ ] Ник `@KAGENAMI_FUN` и аватар — именно эти.

## Часть 2. Промпт для модели, которая придумывает обложку

> Ты делаешь обложку для вертикального пиксельного брейнрот-ролика канала @kagenami_fun. Тебе дают текст озвучки с таймингами слов и список событий ролика. Верни один JSON без пояснений:
>
> ```json
> {
>   "kicker": "EVERY STEP YOU TAKE",
>   "title": ["YOUR AURA", "GOES UP"],
>   "chip": "PIGEONS HAVE LASERS",
>   "frame_time": 23.7,
>   "frame_crop_top": 172,
>   "why": "the busiest, funniest moment: aura, laser pigeons, T-rex, staring moon, alien with AUTOGRAPH? sign"
> }
> ```
>
> Правила:
> - **kicker** — 3–4 слова, начало правила ролика.
> - **title** — две строки до 13 символов, вторая — развязка.
> - **chip** — 2–4 слова, самый кринжовый момент.
> - Всё заглавными латинскими, только символы `A–Z 0–9 @ _ . , ' ! ? - : / + % ° · > < * ✓ $` (без `=`, `#`, `∞`). Слова — из озвучки или близко к ней.
> - **frame_time** — момент, где одновременно видно героя и 2–4 абсурдных события, лицо героя не закрыто. Для страшилок — момент напряжения без полной разгадки.
> - **frame_crop_top** — верхняя строка (на сетке 540×960) среза высотой 450 px, в который попадает всё главное (обычно 150–200).
> - Не упоминай другие каналы, бренды, реальных людей.
