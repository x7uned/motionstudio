## Мир

Один блочный мир на весь ролик (воксельный движок из ролика про Minecraft, своя копия):
- `world.mjs` — суперплоская равнина с деревьями; лаборатория из гладкого камня с пятью стендами (провод, НЕ, И из трёх факелов, ИЛИ, полусумматор) и рядом из 8 копий сумматора; огромный компьютер: стена-экран 112×42 лампы, ряды модулей с дорожками, шины, башни памяти.
- `voxel.mjs` — изометрический рейкастер; лампы светятся сами и переключаются дизерингом; группы блоков проявляются дизерингом.
- `redstone.mjs` — пыль рисуется по верхним граням из буфера попаданий (связи с соседями, свечение, бегущее изменение), факелы и рычаги — маленькими блоками с глубиной; процедурные дорожки с бегущими импульсами на компьютере.
- `scene.mjs` — логика сигналов с настоящими задержками факелов (0,1 с), рычаги, копии, лампы компьютера (такт 1 Гц), режимы экрана (пейзаж → падающие блоки → чат → пейзаж), путь героя, камера.
- `screen.mjs` — картинка экрана из ламп.

## Звук

8-битный синтез (`synth.mjs`), каждый звук длится своё движение: щелчок рычага (пока ходит ручка), гул тока по пыли (пока бежит), тёплое «вкл» лампы, шипение гаснущего факела, шаги героя, свипы камеры на длину перелётов, «шорох» смены картинки на экране, шаги игры, удар такта раз в секунду, трель чипа телефона (пока видна панель), пузыри и точки чата, гонг «10 лет», ускорение «×40 000» (пока идёт), звон «2 часа». Подложка C–Am–F–G: 8 полных циклов, 113,7 BPM, без затуханий, −12 дБ под речью. Звуки, перешедшие через стык, перенесены в начало.
