## P1a · cute-family adapter (items/lib/cute-family.mjs)
`cuteItem(cfg)` turns a copied cute-series draw function `draw(c, gx, gy, o)` (ground anchor, o = { s, t, look, blink, … })
into a prop item with standard states sit · look · wide · happy · sleepy and eased params look wide happy open shut squash
worry; it does the cat/elephant boilerplate (1 % scale steps, look blended by s.lookK, blink → sleepy, shadow, happy hop on
s.acc, box/face). cat.mjs and elephant.mjs unchanged.
How to add the next animal: (1) copy its `*-art.mjs` into items/lib (import `./cute.mjs`, `./roofs-kit.mjs`; turn every
`if (x < k) A else B` into a crossfade, quantise sprite keys ≈ 2.5 %); (2) items/<kind>.mjs = `cuteItem({ kind, source,
desc, hw, hh, S0, mid, headY, box: [x0,y0,x1,y1] at scale 1 around the ground point, opts: (v, {t}) => ({ …map std params
to the drawing's options }), draw })`; optional `states/st/base` for ≤ 1 extra state (or to re-describe a standard one),
`drop` for states it cannot show, `shadow`, `hop`, `blink`; (3) `node tools/sheet.mjs --small <kind>`, fix hw/hh to the
measured footprint. See items/mouse.mjs (≈ 25 lines).
