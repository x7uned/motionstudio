## Что построено
- Харнесс скопирован и заморожен из `breakout/film`: render/captions, mix, synth-core, sheet, cover, cta, cute, tts.py, dev/qa.mjs, dev/pops.mjs. Новые файлы: timeline, game (картинка игры), crt (расчёт экранов), room (мир и камера), overlays, synth, dev/game-png.mjs.
- Один мир: гостиная 90-х вечером (торшер, закатное окно с городом, полосатые обои, ковёр — «квартирный» вид из cat-zoomies, нарисован заново процедурно, чтобы камера могла наезжать без потери чёткости), кинескопный телевизор на низкой тумбе, приставка с картриджем и геймпад на ковре, картриджи на полке. Позже справа плавно выезжает плоский экран (та же комната, без склейки).
- Внутри экранов — наш уровень 64×48 и наш синий ёжик (жёлтые кроссовки, один большой глаз): небо полосами, облака, далёкие холмы и озеро, шахматная скала, водопад из полосок в 1 пиксель (вода / фон через один), пальма. Не спрайты Sega, без логотипов.
- Кинескоп вычисляется (`crt.mjs`), обе картинки — чистые функции t: гауссово размытие луча между соседями по горизонтали, профиль строки с тёмными промежутками (яркие строки шире), лёгкое свечение, на крупных планах теневая маска с точками R/G/B; изгиб стекла (затемнение углов) и блик торшера. Плоский экран — те же пиксели жёсткими квадратами.
- По словам: кадр 0 — ёжик уже бежит, камера уже наезжает; он тормозит у водопада. «An old TV didn't show sharp squares» — наезд в стекло; «A beam… line by line» — макро: луч (точка со следом) прорисовывает 41 строку по точкам, «ELECTRON BEAM»; «red, green and blue» — слова загораются своими цветами; «pixels next to each other blurred together» — два соседних пикселя (белое облако / синее небо) в рамках, их свечения-«колокола» перекрываются, «BLUR». Отъезд, «ARTISTS USED IT»; «waterfalls» — рамка «WATERFALL»; «couldn't make see-through water» — наезд на водопад, «NO SEE-THROUGH WATER»; «thin stripes» — линза «AS DRAWN» (сырые пиксели), на «water, background, water, background» подсвечиваются столбцы с подписями WATER · BACK; «On a TV, the stripes melted» — линза плавно переходит в расчёт кинескопа («ON A TV»), полоски тают в прозрачную воду с холмами за ней, рамка исчезает. Табличка-цитата «WE MADE USE OF THE CRT'S BLURRINESS — NAOTO OHSHIMA, SONIC DESIGNER» (без лица). «Checkerboards» — две плитки: красно-синяя шахматка → фиолетовый («NEW COLOR»), шахматный конус → мягкий свет («SOFT LIGHT»). «Now put the same game…» — отъезд на всю комнату, выезжает и включается плоский экран; «Every pixel…» — две лупы над экранами (OLD TV / NEW SCREEN) на ёжике, «HARD SQUARES»; «The stripes stay stripes» — лупы переезжают на водопад: «CLEAR WATER» против «STRIPES». «CRT filter» — переключатель «CRT FILTER» на плоском экране, экран и лупа плавно переходят в расчёт кинескопа; «collectors» — бирка «COLLECTORS» на телевизоре (без цены). «The game didn't change» — ёжик снова бежит на обоих экранах, «SAME GAME», лёгкий отъезд.
- Концовка (не петля): на «Follow» карточка FOLLOW → FOLLOWING ✓ (кнопочная часть deadliest/film/levels/cta.mjs через breakout/film/cta.mjs) выезжает поверх стены над экранами (x 106–374, y 190–294), колокольчик на «miss», «MORE RETRO SECRETS». Удержание 0,87 с после голоса, музыка — каденция G7 → до мажор с затуханием.
- Звук: только синтез 8 бит: шаги ёжика по прокрутке уровня и торможение, наезды/отъезды, тихий «зуд» на каждой строке луча (ровно строка), три ноты R/G/B, рост свечений, рамка, линза, тики столбцов, «таяние» ровно столько, сколько длится переход, цитата, шахматки, выезд и включение плоского экрана, лупы, щелчок фильтра, качание бирки, карточка подписки. Подложка — чиптюн до мажор, 112 bpm, −12 дБ под речью.

## Известные мелочи
- Макро стекла (≈ 7,8–15,9 с) на телефоне читается как ковёр цветных точек; облако (светлее) и ёжик (тёмное пятно) различимы, но мелко. Пока луч рисует, ещё не прорисованные строки тёмные — так задумано.
- Во время быстрого наезда/отъезда (≈ 6,5–7,8 и 15,9–17,7 с) маска точек даёт кратковременный муар.
- Луч замедлен (41 строка за 4,6 с) — это показ, не реальная скорость; «зелёные холмы» и ёжик — наш рисунок в духе эпохи.
- В общем плане экраны небольшие (телевизор ≈ 184 px сетки), поэтому разницу CRT / плоский несут лупы ×9.
