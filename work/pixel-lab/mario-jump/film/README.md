# «Holding jump makes gravity weaker» · пиксельный ролик про прыжок в Super Mario Bros., петля (2026-10-24)

- Kagenami, English, Dennis · Eleven v4, один дубль (Scribe подтвердил текст). 1080×1920, 30 fps, 49,50 с (1 485 кадров), без оверлея, субтитры караоке.
- **Угол поменян:** идея №16 «Mario falls slower while you hold jump» по коду SMB1 неверна. Кнопка ослабляет гравитацию только на подъёме, с вершины или при отпускании гравитация сильнее в 3,2–3,6 раза. Хук: «holding jump makes gravity weaker. But only on the way up.» (`../facts.md`)
- **Как сделано:** `physics.mjs` — прыжок SMB1 кадр за кадром (высоты 66,0 / 70,3 / 82,5 px совпадают с jdaster64); `mario.mjs` — каждый прыжок на своих часах (замедление на объяснениях, реальное время в «hop / big jump» и в таймерах 0,53 / 0,35 с); свой водопроводчик из частей (`hero.mjs`), свои тайлы (`level.mjs`). Мир повторяется каждые 47 блоков: Марио проходит ровно один период и в конце стоит в первом кадре. Стрелка гравитации (WEAK/STRONG), линейки блоков, следы прыжков, свой пульт с кнопкой A, «двойник» с тапом.
- **QA по MP4 (`qa/qa.json`):**
  - 1 485 кадров, видео 49,500 с; однокадровых вспышек и рывков нет (скан всех кадров рендера и MP4);
  - −16,4 LUFS, true peak −4,4 dBTP;
  - стык картинки 1,54 при соседних 0,95–1,07 (в рендере `frame(END)` = `frame(0)`);
  - стык звука 0,0028 при обычном шаге 0,011 — бесшовно.
- **Разбор «0,053 на стыке» (2026-10-24, вечер).** Это не щелчок в миксе, а хвост кодера AAC: последний кадр AAC добит до 1 024 сэмплов (704 лишних сэмпла, 14,7 мс). Edit list в MP4 обрезает аудио ровно до 2 376 000 сэмплов = 49,5 с (проверено по боксам `elst`/`mdhd`), поэтому плееры зацикливают на правильной точке. Обычное декодирование ffmpeg хвост оставляет, и прежний QA сравнивал добивку с началом файла. На настоящей границе сэмплы идут −0,0557 → −0,0529; стемы sfx и bed на стыке непрерывны. `dev/qa.mjs` теперь меряет стык на длине видео (`seam_audio_jump`), старое значение сохранено как `seam_audio_jump_with_padding`. Микс и файл не менялись, поэтому не переотправлялись.
- **Проигрывание файла:** `mario-jump-pixel.mp4` проигран во встроенном браузере (локальный сервер 127.0.0.1:3220, `dev/play.html`) со звуком, от 0 до конца. Ушло 49,52 с реального времени, 0 пропущенных кадров из 1 485, аудио декодировалось (1,2 МБ), без пауз, ожиданий и ошибок. Скриншоты по ходу (7,0 с и 33,7 с) показали те же сцены, что и раскладка: «SAME START SPEED», таймер «UP».
