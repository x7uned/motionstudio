# Заставки · 5 вариантов для «How Netflix streams» (2026-10-22)

Предложение по просьбе пользователя: красивее и в пиксельном стиле, и с фразой под тему ролика вместо одинаковой «Follow Kagenami». Только предпросмотр. В студию не подключено, `xtuned-outro/v1` не менялся.

- Каждый клип начинается с последних 1,2 с фильма (кадры и звук из `netflix-pixel.mp4`) и продолжает его мир: сетка 540×960 ×2, палитра, пиксельные шрифты, растворения дизерингом, та же шапка.
- **Голоса нет.** Фраза — черновик: на экране она идёт заголовком (в варианте 3 — субтитрами), тайминг взят по темпу Dennis в фильме. Озвучка — платный шаг, только по согласию пользователя.
- Звук: хвост фильма → его же подложка, 8-битные звуки длиной в своё движение, утверждённые клик и арпеджио из пака на FOLLOW. Громкость −22…−28 LUFS: голоса нет, поэтому тише фильма.

## Проверено

- Кадры смотрел из итоговых MP4.
- Однокадровых скачков нет: самые большие изменения растянуты на несколько кадров.
- Шов петли (вариант 3): средняя разница с первым кадром фильма 1,9 из 255.
- Ролики целиком не слушал (humanPlayback=false).

## Ограничения

- Варианты 2–4 не произносят бренд. Нынешняя проверка «Бренд в заставке» (ASR) для них не подходит, нужно решение пользователя.
- Вариант 1 обещает вторую часть. Ставить его, только если вторая часть правда будет.
- В студию это войдёт новой версией пака: подготовленные компоненты + проверенный JSON (вариант, фраза, предметы темы), старые проекты не меняются.

`node netflix-outros.mjs --sheet | --video [1,2] | --stills <n> t1,t2`
