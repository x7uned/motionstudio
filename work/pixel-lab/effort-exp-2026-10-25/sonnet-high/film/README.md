# «Pumpkin face» · эксперимент по усилию · sonnet-high

Не проект студии: без `npm run studio`, без обложки/описания/одобрения. 10,0 с = 300 кадров, 30 fps, 1080×1920 (сетка 540×960 ×2, nearest). Один дубль голоса (Dennis · Eleven v4), положен на t = 0,30 с (время слова = words.json + 0,30). Сделано одним агентом, без субагентов, без сети и платных API.

Файлы
- `pumpkin-face-sonnet-high.mp4` — мастер (4,8 МБ), `pumpkin-face-sonnet-high-phone.mp4` — копия (мастер уже < 30 МиБ).
- Код: `render.mjs` (кадр, караоке-субтитры), `timeline.mjs` (слова и окна движений), `scene.mjs` (ночной мир), `pumpkin.mjs` (тыква), `brain.mjs` (мозг, часы, лучи, метки), `synth.mjs` / `mix.mjs` (звук), `qa.mjs`, `build.sh`.
- `qa/`: `qa.json`, `sheet.jpg` (24 кадра, декодированных из MP4), `safe-zones-3.5.png`, `safe-zones-6.9.png`, `spectrum.png`.

## Что на экране и когда (время слов уже со сдвигом 0,30)
- 0,0–0,9 тыква уже стоит и качается (поставили на землю, колебание затухает), камера медленно наезжает, дизеринговый туман и летучие мыши в движении. Тыква без лица, освещена луной.
- 0,46 «Two»: левая дыра растворяется дизерингом (0,42–0,76). 0,70 «holes»: правая (0,66–1,00). 1,26 «line»: линия-рот прорисовывается слева направо (1,26–1,78).
- 2,28–3,14 «your brain sees»: пунктирные направляющие соединяют три метки (глаз, глаз, рот).
- 3,18 «face»: мозг «решает». Рамка распознавания лица FACE сжимается на лицо, внутри зажигается свеча, глаза расширяются и чуть наклоняются, линия рта выгибается в улыбку (3,18–3,60).
- 3,86–5,10 «In a sixth of a second»: часы с шестью секторами, закрашивается один (шестая), счётчик 0 → 165 MS ровно по слову «second».
- 4,82–5,72 «the area»: тыква плавно уменьшается, часы переезжают значком влево, из дизеринга появляется иллюстрация мозга (вид сбоку, это не скан и не реплика исследования).
- 5,96–6,92 «reads faces»: сигнальные точки бегут от глаз тыквы по двум лучам к «зоне лиц» (вентральная затылочно-височная область). 6,06 «faces»: карточка FACE AREA.
- 6,62 «lights up»: зона лиц загорается оранжевым, три кольца-импульса.
- 7,32–8,0 «for this pumpkin»: свет возвращается по лучу к тыкве, вокруг неё кольцо, свеча ярче.
- 8,06–10,0 финал: подмигивание (8,45–8,85), затем (9,0–9,85) мозг растворяется, камера возвращается к большой улыбающейся тыкве. Кадр 9,97 — крупная светящаяся тыква. Без петли, без «Follow …».

Внешний вид: фиолетовое ночное небо (#1D1430 → #5E4580), луна, холмы, дом с двумя окнами, сухое дерево, забор, мелкие тыквы, туман, светлячки, оранжевая подсветка караоке. Лица и мозг — только иллюстрации. Тыква считается попиксельно при любом масштабе (камера без ресэмплинга).

## Звук (8-бит, всё синтезировано; `synth.mjs`)
- Подложка в ля миноре: треугольный бас, быстрый арпеджио-квадрат, органные аккорды (Am · F · Dm · E), редкие колокольчики, в последние секунды один аккорд с затуханием 0,25 с. Под речью −12 дБ.
- Звуки на движениях, длина каждого = длина его движения: стук покачивания тыквы на 0,18/0,55/0,91; скрежет ножа на каждую дыру и на линию; три тика на трёх рёбрах направляющих; зажигание свечи с арпеджио; тики часов (13 штук, высота растёт) и «динь» на 5,10 (0,35 с, как пульсация часов); свист уменьшения камеры и мерцание появления мозга; «зип» сигнала и 5 писков на прибытиях (0,22 с кольцо); колокола на трёх кольцах (0,85 с); возврат света; писк подмигивания (0,4 с); тихий выдох возврата (0,85 с).

## QA (по готовому MP4)
- Кадров 300, 10,000 с видео, аудио 10,005 с (AAC-паддинг), 30 fps, h264 1080×1920.
- Громкость −16,0 LUFS, LRA 5,2, true peak −4,5 dBFS (лимитер 0,85 до loudnorm, цель −16 / −1,5 dBTP).
- Однокадровых «хлопков» нет, резких скачков нет. Максимальная разница соседних кадров 2,03 (t = 9,47, камера возвращается).
- Контактный лист `qa/sheet.jpg` из MP4 просмотрен. Оверлей безопасных зон на кадрах 3,5 и 6,9 с (оба взяты из MP4): важное внутри главной зоны (мозг, тыква, значок часов, карточка FACE AREA), субтитры в строке y 1360–1500, низ и верх — только фон.
- Воспроизведение: мастер проигран целиком во встроенном браузере (`<video>` с локального 127.0.0.1): длительность 10,0 с, 299 колбэков кадров плюс первый, максимальный разрыв 33 мс, реальное время 10,05 с. Видео играло без звука (muted), звук в браузере не слушал.
- Время рендера кадра 40–140 мс, полный рендер видео 18 с.

## Известные ограничения и что не проверено
- На слух звук не проверялся (только числа громкости и спектрограмма `qa/spectrum.png`). Совпадение событий со звуком — по общим константам окон, не по записи.
- Мозг — условная иллюстрация: контуры извилин процедурные (изолинии шума), расположение зоны лиц схематично; цифра «165 MS» — по Hadjikhani et al., NeuroReport 2009 (около 165 мс), на экране без ссылки.
- Тыква при масштабе 0,7 небольшая: хорошо читается на телефоне, но мельче, чем в первых 4,8 с.
- Нижняя треть кадра (ниже субтитров) — тёмный фон с травой, намеренно пустой по правилам безопасных зон.
- Тест на реальном телефоне и в приложениях TikTok/Reels не проводился.
