# Промпт: каждый ролик сразу на двух языках — английском и русском

Версия 1 (2026-10-27). Для агента в Motion Studio, который делает пиксельные истории для @kagenami_stories по `STORY-SERIES-PROMPT.md` и `STORY-WRITING-PROMPT.md`. Этот файл добавляет одно правило: **каждая часть выходит в двух роликах — EN и RU. Картинка одна и та же, меняется только язык.**

---

## 1. Идея и экономия

Больше всего лимитов уходит на то, чтобы написать код картинки: миры, персонажей, кадры от первого лица, свет, предметы. Этот код пишется **один раз** и служит обоим языкам.

| Не меняется (общее для EN и RU) | Меняется (языковой слой) |
|---|---|
| миры, персонажи, позы, кадры от первого лица, свет, камера | текст рассказчика и реплики |
| порядок кадров, события, переходы | озвучка (свой дубль на каждый язык) и тайминги слов |
| звуки событий и эмбиент (по тем же меткам) | субтитры |
| счётчик как механика (цифры тикают так же) | все надписи на экране: титул, счётчик, вывески, экраны телефонов, записки, экран выбора |
| безопасные зоны, стиль, палитра | обложка и описание |

Русская версия стоит:
- адаптацию текста;
- один платный дубль озвучки;
- Scribe;
- две колонки в таблицах (`cues.json`, `strings.json`);
- один локальный рендер (это время процессора, а не токены);
- точечную проверку кадров с текстом.

**Нельзя ради русской версии перечитывать и переписывать модули рисования.** Если для RU пришлось лезть в код мира или персонажа, значит, текст был «впечён» в картинку. Его нужно вынести в языковой слой (раздел 4), один раз и навсегда.

---

## 2. Порядок работы над одной частью

1. **Сценарий EN** по `STORY-WRITING-PROMPT.md`.
2. **Сразу RU-адаптация** (раздел 3) и таблица меток `cues.json`: у каждой метки картинки есть слово в обоих текстах.
3. **Показать пользователю оба текста**, кастинг голосов на двух языках и число символов озвучки для каждого языка: это два платных запроса. Озвучивать только после его «да».
4. **Озвучка EN и RU**, оба через кэш, затем Scribe для каждого языка: `eng` и `rus`.
5. **Картинка один раз:** миры, персонажи, кадры от первого лица — как обычно. Всё время привязывать к меткам, а не к английским словам. Весь текст на экране брать через `T(key)`.
6. **Стоп-кадры EN** — как обычно.
7. **Стоп-кадры RU** — только кадры с текстом: титул, счётчик, каждая надпись или экран, 3–4 кадра субтитров, экран выбора.
8. **Рендер EN, потом RU**, по одному через `render-lock.sh`: `LANG=en ./build.sh` и `LANG=ru ./build.sh`.
9. **Проверка обоих MP4:** `qa.mjs`, безопасные зоны, и **каждый проигрывается целиком со звуком**. Контактные листы EN и RU рядом: те же кадры в том же порядке.
10. **Отправить пользователю** оба ролика, обе обложки, оба описания. Пометка «не одобрено».

## 3. Русский текст

- **Это адаптация, а не перевод слово в слово.** Те же события, в том же порядке, с теми же числами, именами и предметами-ружьями. Звучит так, как сказал бы живой рассказчик.
- **Те же правила, что для английского:**
  - второе лицо «ты», настоящее время;
  - простые разговорные слова и короткие фразы, одна мысль на фразу;
  - хук первой фразой со ставкой и числом;
  - без «Представь…», «А вы знали…»;
  - без канцелярита и редких слов.
- **Метки.** У каждой метки из `cues.json` в русском тексте есть своё слово: то, на котором в картинке происходит событие («стучат», «пальто», «свет»). Если при адаптации метка потерялась, переписать фразу, а не двигать картинку.
- **Длина.** Русский дубль не длиннее английского больше чем на 10 %. Длинный текст — сокращать, а не ускорять: скорость речи и паузы не трогаем.
- **Числа** писать словами, в нужном падеже: «в три двенадцать ночи», «одиннадцать минут». Иначе TTS может прочитать неверно. Числа на экране (`10:59`, `DAY 9`) остаются цифрами.
- **Имена** те же, в русской записи: Нина, мистер Хейл, Бисквит.
- **Реплики героев** до 8 слов, как в EN.
- **Выбор:**
  - одно короткое слово на вариант, лучше до 8 букв: ОТКРЫТЬ / ЖДАТЬ, ПЕРЕДНЯЯ / ЗАДНЯЯ, ДЕРЖАТЬ / ОТПУСТИТЬ;
  - слова не должны совпадать по корню;
  - фраза в конце: «Пиши в комментариях: ОТКРЫТЬ или ЖДАТЬ.»
- **Chapter 2+:** карточка «БОЛЬШИНСТВО ВЫБРАЛО: …» и фраза «Большинство из вас выбрало…».
- **Название серии** по-русски, коротко и с образом: «ДВЕ ДВЕРИ», «ОДИННАДЦАТЬ МИНУТ». Записать в `series.json`.

## 4. Языковой слой в коде

Один раз на серию (лучше — в общем наборе, чтобы следующие серии получили его даром).

### 4.1. Файлы части
```
film/
  narration.en.txt   narration.ru.txt        текст рассказчика и реплик (как сейчас narration.txt)
  voice/en/words.json   voice/ru/words.json   тайминги слов после Scribe
  cues.json          метка → слово в каждом языке
  strings.json       ключ → надпись в каждом языке
```
Пример:
```json
// cues.json — метка: [слово, номер вхождения]
{ "knock":  { "en": ["knocks", 1], "ru": ["стучат", 1] },
  "coat":   { "en": ["coat", 2],   "ru": ["пальто", 2] } }
// strings.json
{ "title":   { "en": "TWO DOORS",           "ru": "ДВЕ ДВЕРИ" },
  "chapter": { "en": "CHAPTER 1",           "ru": "ГЛАВА 1" },
  "alert":   { "en": "MISSILE ALERT",       "ru": "РАКЕТНАЯ ТРЕВОГА" },
  "choiceQ": { "en": "WHICH DOOR DO YOU OPEN?", "ru": "КАКУЮ ДВЕРЬ ОТКРОЕШЬ?" },
  "optA":    { "en": "FRONT",               "ru": "ПЕРЕДНЯЯ" } }
```

### 4.2. Правила кода
- **Язык** выбирается переменной `LANG=en|ru` (по умолчанию `en`). От неё зависят текст, тайминги, `cues.json`, `strings.json`, файлы на выходе (`final-en.mp4`, `final-ru.mp4`, `stills/ru/…`).
- **Время только через метки.** В `timeline.mjs` вместо `W("knocks")` писать `C("knock")` (и `C("knock", "end")`): функция берёт слово для текущего языка из `cues.json` и ищет его в `voice/<lang>/words.json`. `SHOTS`, `EV`, камеры и звуки строятся из `C(...)`, поэтому для RU они сами встают на русские слова.
- **Нормализация слов** в поиске должна оставлять кириллицу: `s.toLowerCase().replace(/ё/g, "е").replace(/[^a-zа-я0-9'-]/g, "")`. В текущем `norm` стоит `[^a-z0-9'-]`, и он стирает русские слова целиком.
- **Не найдена метка — ошибка**, а не тихий сдвиг. Скрипт падает и пишет метку и язык.
- **Анимации внутри кадра** задавать от меток или от доли длины кадра, а не абсолютными секундами от начала ролика. Короткие действия с собственной длиной (захлопнулась дверь — 0,4 с) остаются как есть.
- **Ни одного слова в картинке.** Вывески, экраны телефонов, записки, табло, подписи к вещам рисуются шрифтом во время рендера через `T("key")`. Не делать их PNG-текстурами и не рисовать буквы пикселями внутри модулей мира.
- **Субтитры** строятся из `narration.<lang>.txt` и слов этого языка. Группы до 22 символов или 5 слов. Длинное русское слово может стоять в строке одно.
- **Вмещение текста.** Русский текст длиннее. Функция `fitText(font, str, maxWidth, scaleMax, scaleMin)`:
  - сначала уменьшает масштаб: титул от 6 до 4, слова выбора от 6 до 4;
  - потом делит текст на две строки по пробелу;
  - выходить из безопасных зон нельзя.
- **Звук.** `synth.mjs` и `mix.mjs` берут события из тех же `C(...)`, эмбиент тянется до `END` этого языка. Новых звуков для RU не нужно.
- **END** = последнее слово этого языка + тот же хвост на экран выбора.

### 4.3. Кириллица в пиксельном шрифте (один раз)
В `renderer/pixel/raster.mjs` у шрифтов `MAIN` (5×7) и `TINY` (3×5) только латиница.
- Сделать **новый файл** `renderer/pixel/font-cyr.mjs`, `raster.mjs` не трогать. Он экспортирует `MAIN_CYR` и `TINY_CYR`: копия латинских глифов плюс А–Я и Ё в той же сетке и том же стиле.
- Совпадающие по виду буквы берутся из латиницы: А В Е К М Н О Р С Т Х. Широкие Ж Ш Щ Ы Ю допускают ширину 5 даже в `TINY`, как M и W.
- Проверка: лист со всеми буквами в масштабах 2, 3 и 6, и строки «СЪЕШЬ ЖЕ ЕЩЁ ЭТИХ МЯГКИХ ФРАНЦУЗСКИХ БУЛОК» и «ПИШИ В КОММЕНТАРИЯХ». Все буквы читаются, Ш/Щ, Ь/Ъ/Ы, З/Э различимы.
- В RU-версии весь текст рисуется этими шрифтами.

## 5. Голоса

- **Рассказчик RU.** Нужен спокойный, глубокий мужской голос с родным русским. Перед первой серией сделать короткую пробу одной фразы (≈ 100 символов, это платно — спросить пользователя):
  - Dennis на eleven_v4 с `language_code: "ru"`;
  - 1–2 русских рассказчика из Voice Library.

  Выбирает пользователь. Записать в `series.json` → `voices.ru.narrator`.
- **Персонажи.** Сначала пробуем тот же голос, что в EN, с `language_code: "ru"`: так герой звучит одинаково на обоих языках. Если акцент мешает, подобрать русский голос того же типа (возраст, пол, характер) и показать пользователю. Кастинг по языкам — в `series.json`.
- **Порядок озвучки и обработка** («через дверь», рация, радио) — как в `STORY-SERIES-PROMPT.md`, раздел 3. Один дубль на язык, тайминги из Scribe с `language_code: "rus"`, без ускорения и растяжения речи.
- **Кэш** — отдельный ключ на язык. Повторно не оплачивать.

## 6. Серия на двух языках

- **`series.json`:**
  - `languages: ["en","ru"]`;
  - название `{en, ru}`;
  - имена и слова выбора `{en, ru}`;
  - голоса по языкам;
  - победивший вариант по каждой части отдельно для каждого языка.
- **Голоса зрителей** на двух аудиториях считаются отдельно. По умолчанию каждая версия идёт за своей аудиторией: начала веток уже написаны для обоих вариантов (`STORY-WRITING-PROMPT.md`, раздел 3а), общая середина одна, поэтому это почти бесплатно. Если пользователь скажет вести обе версии по одному варианту, делать так. Победителя называет пользователь, агент его не выдумывает.
- **Где выкладывать RU** — спросить пользователя, на каком аккаунте. Ник на обложке ставить только тот, который он назвал.

---

## 7. Обложка и описание RU

- **Обложка** — та же раскладка и тот же кадр, что у EN (`kagenami-stories/COVER-PROMPT.md`), меняется только текст (шрифт `MAIN_CYR`):
  - кикер `ГЛАВА 1` (в финале `ФИНАЛ`);
  - название по-русски, с `fitText`;
  - плашка-вопрос `ПЕРЕДНЯЯ ИЛИ ЗАДНЯЯ?`.
- **Описание:** около 10 слов по-русски с темой, один эмодзи, до 4 хэштегов (1–2 широких и 2 по теме). Пример: «Пришельцы делают копии. В дверь стучат две сестры. Какую впустишь? 🚪 #история #страшилка #пиксельарт #выбор»

## 8. Чек-лист двух версий

- [ ] RU-текст: та же история, все метки на месте, длина не больше EN + 10 %, простые слова, числа словами.
- [ ] Оба текста и стоимость двух озвучек показаны пользователю, есть его «да».
- [ ] В коде нет `W("англ. слово")` — только `C("метка")`. Нормализация оставляет кириллицу.
- [ ] Ни одного слова в картинке: все надписи через `T(key)` и `strings.json`.
- [ ] Кириллица в `font-cyr.mjs`, лист букв проверен глазами.
- [ ] RU-стоп-кадры с текстом проверены: ничего не вылезает за безопасные зоны и рамки.
- [ ] Оба MP4: `qa.mjs` чистый, проиграны целиком со звуком, контактные листы совпадают по кадрам.
- [ ] Две обложки, два описания. Отправлено с пометкой «не одобрено».
