Сценарий, голос, тайминги, порядок кадров, город, жители, числа, звук и концовка — как в v1. Не одобрен: одобряет только пользователь. `../film/` не тронут.

**Ни одного ассета, фона, кита или производного из каталога Kagenami.** Никаких спрайтов, тайлов, логотипов, шрифтов и звуков Nintendo: спрайт и тайлы нарисованы нами «в духе NES», без буквы на кепке.

## Что изменилось по сравнению с v1
- **Марио — настоящий игровой спрайт** (`assets/mario.mjs`, v1 удалён полностью): 16 × 32 спрайт-пикселя (= два блока 16 × 16 = 1,55 м), три плоских цвета + прозрачность — красный (кепка, комбинезон), оливково-коричневый (волосы, усы, рубашка, ботинки), оранжевая кожа (лицо, руки, пуговицы). Без контура, градиентов, дизеринга внутри, сглаживания и кругов: каждая поза — ручная строковая сетка (`"..RRRRR.."`), каждый спрайт-пиксель — точный квадрат N × N пикселей сетки 540 × 960 (×2 nearest → 1080 × 1920).
- **Позы:** idle, run ×3 (кадр меняется каждые 5 видеокадров, кадр смены — 50 % клеточный дизер двух кадров), skid (торможение в конце обоих разбегов назад), jump (кулак вверх; также зависание, падение, нырок в портал), duck (присед перед прыжком), win (гордая поза в конце), look (голова и глаз на 1 спрайт-пиксель выше), point (рука вперёд-вниз, к коленям), land (один кадр приседа, потом idle). Смена позы и разворот — упорядоченный дизер Байера по клеткам спрайта за ~3 кадра (клетка целиком из одной позы, квадраты остаются чистыми); никаких альфа-размытий и смен в один кадр.
- **Целочисленный масштаб на план, нигде дробного зума спрайта.** Фокусное расстояние камеры города следует из N (1,55 м на глубине Марио = 32·N px), поэтому спрайт и город всегда в одном масштабе; внутри плана камера только едет. Смена N — растворение целого кадра через дизер между двумя рендерами (~0,3 с). Масштабы: пролог N = 8 (блок 128 px); город N = 8 (Марио 256 px = 26,7 %); общий план над крышей N = 3 (10 %); колени «SUPERPOWER» N = 14 (46,7 %; в черновике было N = 16 — кепка заходила в верхнюю зону UI, исправлено); окна игры: «два блока» N = 2, прыжки на 5 блоков N = 1.
- **Камера отодвинута:** больше фасада, тротуара, клумбы и прохожих вокруг Марио; тротуар на строке 620 (подошвы ≤ y1240 из 1920). Прыжок на 11 м — камера по-прежнему едет вверх по фасаду, шире: видно два этажа; номера этажей, рулетка, бабушка с лейкой, мальчик с телефоном, голуби — на своих словах.
- **Пролог и окна игры в той же блочной манере** (`assets/game-level.mjs`, переписан): плоские тайлы 16 × 16 нашего рисунка — земля, кирпич, «?»-блок и использованный блок, труба, кусты, облака, холмы, монета (ширина по |cos|, шагами спрайт-пикселей). Блоки уровня стоят на целых координатах. Марио бежит, бьёт «?» — монета вылетает, на «bring» открывается портал, он въезжает в его центр и растворяется по клеткам (без уменьшения). **Резкая склейка на кадре 179 (5,967 с) — как в v1.** В городе он выезжает из того же портала и проявляется по клеткам.
- Плоская тёмная тень на тротуаре (одна строка спрайта, края дизером), сужается и бледнеет с высотой. Белый шлейф прыжка — плоские полупрозрачные силуэты того же спрайта (без дизер-шума). Золотое сияние коленей рисуется за спрайтом.
- Кирпичные блоки в натуральную величину (`props.cube`) носят ту же плоскую сетку кирпича 16 × 16, что и тайл в окне игры.
- Звук: синтез v1 без изменений, кроме шагов — теперь они стоят на кадрах смены run1/run3 спрайта (см. `synth.mjs`).
- Плашки и подписи не уменьшались (размер v1).

## QA (из финального `mario-real-pixel.mp4`)
- 1978 кадров = 65,933 с (как v1), аудио 65,941 с. Мастер 45,5 МиБ (H.264 CRF 16 + AAC 192k); копия для отправки `mario-real-pixel-max.mp4` 26,7 МиБ (2-pass 3200k).
- Громкость −16,5 LUFS, true peak −4,5 dBFS, LRA 2,5; хвост: последние 0,5 с −30,8 дБ → 0.
- Однокадровые вспышки: 0. Резкие скачки: 1 — 5,97 с (кадр 179), намеренная склейка портала. Шаги цикла бега (кадр смены = 50 % клеточный дизер) и растворения поз (~3 кадра) — малые разности соседних кадров; детектор `dev/qa.mjs` (скачок > 2,5 и > 3× соседей; вспышка = кадр, отличающийся от обоих соседей) их не отмечает. Растворения смены N (~0,3 с = 9 кадров) тоже не отмечены.
- Рост Марио на 30 кадрах контактного листа (`qa/mario-size.json`, высота спрайта 32·N): мин 10,0 % (общий план над крышей, N = 3), медиана 26,7 % (N = 8), макс 46,7 % (колени, N = 14 — единственный план > 40 %). Видимые пиксели позы: мин 8,4 % (поза прыжка при N = 3 ниже 32 строк), медиана 26,7 %.
- Квадраты (`qa/squares.json`, `qa/sprite-zoom.png`): по одному кадру на масштаб (игра N 8, город N 8 ×2, общий N 3, колени N 14, финал N 8) — все клетки спрайта однотонные N × N; исключение — 13 клеток при N 14 под надписью «SUPERPOWER» (наложение подписи, не спрайт). Зум из кадров рендера ×2 — чистые квадраты.
- Safe zones v1 (15 кадров из MP4, `qa/safe-zones-sheet.jpg`): Марио, числа, окна игры, карточка — в главной зоне; линия планки 2,45 м — в нижней зоне ожидания (как в v1, подпись в главной).
- Воспроизведение: `mario-real-pixel.mp4` проигран во встроенном браузере (сервер `pixel-lab-files`, без mute): `playing` с 0, `ended` на 65,93 с, аудио декодировалось (1,7 МБ), 4 пропущенных кадра из 2108 — панель браузера была скрыта (фоновая страница), это не человеческое прослушивание.

## Известное / не проверено
- Человеком не просмотрено и не прослушано.
- Поза «point» отличается от idle только рукой вперёд-вниз — читается слабо; «look» — сдвиг головы на 1 спрайт-пиксель (как в брифе).
- Во время растворения смены N (общий план над крышей, колени) ~0,3 с видны оба плана сквозь дизер — так задумано, но это не «склейка на действии».
- Окна игры с прыжком на 5 блоков — Марио при N = 1 (32 px сетки = 64 px кадра): иначе 5 блоков не помещаются в окно.
- Шаги в звуке перенесены на кадры бега спрайта; остальной звук не менялся.
