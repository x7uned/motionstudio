# «Pac-Man level 256» · пиксельный ролик про «раскол экрана», петля (2026-10-24)

- **Аккаунт:** Kagenami. **Голос:** English, Dennis · Eleven v4, Plain English, один дубль.
- **Заказ:** идея №69 из разбора залетевших рилсов (пользователь: «надо реализовать 59, 60, 63 и 69»).
- **Формат:** 1080×1920, 30 fps, 71,47 с (2 144 кадра). Без оверлея, картинка до краёв (под лабиринтом — жизни, испорченный ряд фруктов и панель автомата до низа кадра), субтитры караоке.
- **Сценарий:** `../script.md` v1 (192 слова); факты — `../facts.md`, источники — `credits.txt`.
- **Концовка — петля.** «…Funny, because» → «Pac-Man has no last level. Yet level 256 breaks the screen in half.» Первый и последний кадр — раскол экрана.

## Как сделано

Лабиринт, спрайты Pac-Man и призраков — из ролика `../../pacman/film` (копии `maze.mjs`, `sprites.mjs`). Всё остальное в `render.mjs`:
- **мусор правой половины:** 270 тайлов (буквы, цифры, символы, обрывки стен) печатаются по одному, с правого верхнего угла вниз по столбцам к середине (как в разборе Hodges), почти по одному на проход 256-кратного цикла; виден в первом кадре, растворяется для объяснения и печатается снова на словах «draws other parts of its memory»;
- **Pac-Man** ходит по кольцу коридоров левой половины (целое число кругов за ролик), красный идёт следом и на «catch you» догоняет; смерть, «GAME OVER», новая жизнь проявляется до стыка; розовый проходит сквозь стены правой половины на «the walls stop working»;
- **панели:** байт (значения 0 → 255 шагами, «LEVEL 1 = 0», «LEVEL 256 = 255»; каждая смена битов растворением), «255 + 1» (перенос справа налево, девятый бит выпадает, «= 0»), «THE FRUIT LOOP» (счётчик и 256 проходов против 7), точки 244 против 168 («CAN'T WIN»), счёт 3 333 360, «1999» и часы «~6 HOURS».

## Звук

8-битный синтез (`synth.mjs`), своя мелодия, без звуков и сирены оригинала. Каждый звук длится своё движение: блип на каждый напечатанный тайл (пока печатается), блипы значений байта, восемь щелчков переноса и падение девятого бита (пока падает), 256 тиков цикла, фрукты, скольжение розового призрака сквозь стены, наполнение полос, смерть Pac-Man (пока длится), прокрутка счёта, тики часов, свипы переездов камеры. Подложка Am–F–C–G, 36 тактов, без затуханий, −12 дБ под речью; пока виден мусор, в ней «сбоят» ноты.
