# «From the lightest animal to the heaviest» · пиксельный ролик, петля (2026-10-23)

- **Аккаунт:** Kagenami. English, Dennis · Eleven v4, один дубль (`narration.txt`, 242 слова).
- **Формат:** 1080×1920, 30 fps, 74,900 с (2 247 кадров). Без оверлея, кроме табло весов (данные) и субтитров.
- **Стиль:** тот же, что в первом ролике серии (`../../animals/film`): милые пиксельные животные смотрят в камеру, мир боком, светило за головой.
- **Мир:** луг с ульем → кубинская опушка → поле с амбаром и шахтой → крыши деревни → парк → пастбище → река → саванна на закате → ночной океан → берег на рассвете → тот же луг (первый кадр).
- **Порядок:** пчела 0,1 г, колибри-пчёлка 1,6 г, мышь 20 г, кошка 4 кг, собака 20 кг, человек 62 кг, лошадь 500 кг, бегемот 2 т, слон 6 т, синий кит 150 т.
- **Мотив ролика — весы:**
  - 1 000 000 000+ пчёл = кит;
  - 16 пчёл = колибри;
  - 200 мышей = кошка;
  - все собаки = все дикие звери;
  - все люди ×20;
  - 8 человек = лошадь;
  - 4 лошади = бегемот;
  - 25 слонов = кит;
  - сердце кита ≈ 3 человека.
- **Петля:** «So how many bees would it take to balance this giant?» → «More than a billion honeybees weigh as much as one blue whale.»
- **Факты и источники:** `../facts.md`, `credits.txt`.

Устройство — как в первом ролике: `timeline.mjs`, `world.mjs` (время суток по кругу, ключи из таймлайна), `levels/*.mjs` (строили помощники по `BRIEF.md`), `levels/scale.mjs` (табло), `levels/*-motions.mjs` → `cues.mjs` → `synth.mjs`, `mix.mjs`, `cover.mjs`. Проверка — `../../animals/qa.mjs`, результат в `qa/`.

Пересборка: `node render.mjs --video && node synth.mjs && node mix.mjs`.
