# Пиксельные компоненты · renderer/pixel

Библиотека готовых компонентов для пиксельных роликов («Пиксель-фильм», `docs/pixel-film.md`). Создана 2026-10-21 по просьбе пользователя: «если нету, то создай… можно создать первую землю… она хорошо получилась, я хочу, чтобы ты ее дальше еще использовал».

Компоненты — подготовленный код, а не генерируемый: сцена задаётся параметрами (вид камеры, точки, маршрут, время). Каждый кадр — чистая функция времени.

## Основа: `raster.mjs`

- `Canvas(w, h, bg)` — растр на сетке 540×960; `save(path, scale)` увеличивает без сглаживания (×2 → 1080×1920).
- Примитивы: `px rect rrect frame line poly disc ring ellipse ering dither tint sprite blit text measure`.
- `bayer(x, y)` — порог упорядоченного дизеринга 4×4. `fade(c, a)` — вид холста, через который всё рисуется с пиксельным растворением (0..1). Так ничто не появляется и не исчезает за один кадр.
- Шрифты `MAIN` (5×7) и `TINY` (3×5): свои, пока только латиница, цифры и знаки (`@ _ . , ' ! ? - : / + % ° · > < * ✓ $`).
- `loadImage(path, w, h, opts)` — спрайт через sharp (уменьшение, палитра, вырезка).

## Земля · `earth.mjs` · v1

Пиксельная планета: орфографическая проекция, ступени освещения с дизерингом, день и ночь по подсолнечной точке, огни городов на ночной стороне, ореол атмосферы, гладкие берега при любом приближении. Проверена в ролике «What happens when you tap» (Токио → Лондон) и на обложке к нему.

```js
import { Canvas } from "./raster.mjs";
import { drawGlobe, project, routeSamples } from "./earth.mjs";
const c = new Canvas(540, 960, "#000000");
const view = { lat0: 38, lon0: 72, R: 212, cx: 270, cy: 440 };   // центр вида (широта, долгота), радиус в пикселях сетки
drawGlobe(c, view, { lat: -11, lon: 150 }, { alpha: 1, clip: [0, 190, 540, 680] });  // sun = подсолнечная точка
const p = project(view, 35.68, 139.69);                            // экранная точка Токио, p.visible — на видимой стороне
const r = routeSamples([[139.7, 35.7], [103.8, 1.3], [-0.1, 51.5]]); // [долгота, широта] → {pts, cum, km} по большим кругам
```

- **Наезд.** `R` растёт экспоненциально (212 → 9000), центр вида плавно переходит к городу. На большом `R` берега остаются гладкими: `groundSmooth` делает билинейный порог маски 0,25°.
- **Время суток.** `sun.lon` 150 даёт день в Токио и ночь в Лондоне. Чтобы показать, что прошли сутки, долготу солнца прокручивают на 360°.
- **Растворение.** `alpha` растворяет планету дизерингом: так она уходит, когда из неё «вырастает» диорама.
- **Маркеры.** Пины, маршруты, узлы и подписи рисуются поверх по `project()`. Флаги и логотипы накладываются в полном разрешении и только из снимков Wikimedia Commons с лицензией.

### Ограничения v1

- Берега обведены вручную с точностью около 1°; Япония, Британия и Ирландия подробнее. Это иллюстрация, а не карта. Точный контур (Natural Earth, общественное достояние) можно подключить, только если пользователь разрешит загрузку.
- Огни городов — детерминированный узор с меньшей плотностью в пустынях и на севере, а не реальная карта населения.
- Подводные кабели и узлы сети в ролике показаны условно, их здесь нет: маршруты задаёт сцена.

Превью: `node renderer/pixel/earth-preview.mjs` → `earth-preview.png` (общий вид с маршрутом, Америка ночью, Япония крупно, Британия крупно).

## Кириллица · `cyrillic.mjs` · v1 (2026-10-29)

Русские буквы для `MAIN` (5×7) и `TINY` (3×5) в том же стиле. `raster.mjs` не изменён, поэтому старые ролики рисуются как раньше. Русский ролик собирает шрифты так:

```js
import { MAIN, TINY } from "./raster.mjs";
import { withCyrillic, lcRu, CanvasRu } from "./cyrillic.mjs";
const c = new CanvasRu(540, 960, "#000000");          // вместо Canvas: умеет знаки над строкой
const M = withCyrillic(MAIN), T = withCyrillic(TINY, "tiny");
c.text(M, "СУПЕРСИЛА", x, y, col, { scale: 3 });
c.text(M, lcRu("52 км/ч"), x, y, col, { scale: 3 });   // строчные «к м с ч а» для единиц
```

- 11 букв, похожих на латинские (А В Е К М Н О Р С Т Х), берут латинский знак; остальные 22 нарисованы.
- Текст выводится заглавными; строчные есть только для единиц измерения (`lcRu`).
- Буквы полного размера: черта «Й» и точки «Ё» стоят НАД строкой (`glyph.up`, рисует только `CanvasRu`; `fade()` его наследует), хвосты «Д», «Ц», «Щ» уходят НИЖЕ строки. Между строками текста оставлять запас: 2 строки шрифта сверху и 1 снизу.
- Лист проверки: `node renderer/pixel/cyrillic-preview.mjs` → `cyrillic-preview.png`.
- Привязка анимации к словам в роликах (`norm` в timeline.mjs) пока выбрасывает кириллицу: русскому ролику нужен `[^a-zа-яё0-9'-]`.

## Добавлять новые компоненты

Новый компонент — отдельный файл `<имя>.mjs` с версией в этом README. Старое поведение не менять: улучшение = новая версия (`earth-v2.mjs`), ролики со старой версией остаются как есть.
