# Среды и параллельные ролики

Скилл работает в любом чат-агенте с shell: всё управление — `npm run studio -- …`, все роли — файлы `prompt.md`/`schema.json`/`answer.json`. Хуки и сабагенты только помогают.

## Что проверено на практике (Claude Code, desktop, 2026-10-21)
- Сабагент `general-purpose` имеет Bash и инструмент запуска сабагентов: выполнил `npm run studio -- status`, запустил вложенного `studio-role` (Read/Write, без shell) и два `studio-role` одним сообщением — оба ответили.
- PostToolUse-хук `scripts/agent-run-hook.mjs` записывает `MOTION_STUDIO_RUN=<id>`, напечатанный в Bash **сабагента**, на сессию ведущего агента (`data/agent-runs/<session>.json`). Значит Stop-хук держит ведущего, пока не готовы все ролики, созданные его сабагентами. Сам сабагент Stop-хуком не удерживается.
- Разные сессии чата держатся каждая только своими роликами (тест `scripts/agent-hooks.test.ts`).

## Схема A · одна сессия на ролик
Любая среда. Сессия: бриф → `create` → `run <id>` → задания → `run` … → показ пользователю. Движок ведёт все ролики одновременно; рендеры идут по одному. Решения (аккаунт, платная озвучка, одобрение) каждая сессия спрашивает сама.

## Схема B · ведущий + сабагент на ролик (Claude Code)
Ведущий собирает решения пользователя (тема, аккаунт, шаблон) и раздаёт сабагентам `general-purpose` задачу вида:
> Папка студии …; прочитай `.agents/skills/motion-studio/SKILL.md`. Бриф: … Аккаунт: `--brand …`, `--agent "claude-code/<модель>"`. Сделай `create`, затем цикл `run`/`task`/`submit` до exit 0 (или 11 — тогда верни, какое решение нужно). Независимые роли отдавай сабагентам `studio-role` и отправляй с `--isolated`. Не одобряй, не запускай платное, не перезапускай движок. Верни id, путь MP4 и итог проверок.

Все сабагенты — одним сообщением, чтобы шли параллельно. Если сабагент вернулся до готовности, ведущий продолжает `run <id>` сам (Stop-хук напомнит).

## Схема C · один агент, несколько роликов
Для сред без сабагентов: `create` для каждого, затем `run <id1> <id2> …` — возвращается, как только любому ролику нужен агент (`MOTION_STUDIO_FOCUS=<id>`), остальные продолжают работать. Ответь на задания этого ролика и снова `run` со всеми незавершёнными id.

## Codex
Хуки — `.codex/hooks.json` (те же скрипты). Сабагенты Codex, если доступны, — для независимых ролей; иначе ответ без `--isolated`. Движок можно запустить из shell Codex, если у него есть вход Tavily, или включить `engine.autostart`.

## Агент без хуков
Держи цикл сам: не заканчивай ход, пока `run` не вернул 0/11/13/1/2. Независимые роли выполняй по одной с чистого листа: читай только папку задания, не опирайся на свои прошлые ответы.

## Windows
- Команды те же (`npm run studio -- …`) в PowerShell, cmd или Git Bash. Установка — `install.md`.
- Claude Code на Windows выполняет хуки через Git Bash, поэтому `"$CLAUDE_PROJECT_DIR/…"` в `.claude/settings.json` работает. Хуки Codex (`.codex/hooks.json`) вызываются относительным путём `node scripts/…` из папки студии. Если хук не сработал, работа не блокируется — держи цикл `run` сам.
- Сабагент `studio-role` работает только с файлами (Read/Write) и от ОС не зависит.
