# Роли агентного режима

Имя роли в задании = папка, куда студия сохранит ответ. Промпт каждой роли — тот же, что раньше получали GPT‑6.1 Sol или Claude Opus 5.5; в `meta.json` поле `hint` показывает, какая модель исполняла роль раньше (для ориентира, не требование).

| Роль (папка) | Что делает | Изоляция |
|---|---|---|
| `research-query` / `query-agent` | Планировщик поиска: суть вопроса, 2 запроса Tavily, домены первоисточников | — |
| `research-agent` | Исследователь: факты с дословными цитатами из прочитанных страниц, оговорки, 3 угла, 10 начал (по формулам раздела «Первая фраза» в `.agents/skills/reel-script-craft/SKILL.md`, без запрещённых начал). Цитаты сверяются программно — копируй дословно | — |
| `narrative-writer`, `budget-repair-*`, `narrative-repair-*` | Один цельный рассказ одним абзацем, причинная связь, бюджет слов; открывается самым сильным началом (первые 1–2 с решают удержание, `docs/publishing-and-retention.md`) | — |
| `editor-*` | Независимый редактор рассказа | сабагент |
| `facts-*`, `claims`, `verification*` | Извлечение и независимая проверка утверждений (если фактчек не выключен) | сабагент |
| `segmentation-*` | Разметка рассказа на сцены без изменения слов: склейка narration должна точно совпасть с fullText | — |
| `voice-director` | Редкие указания подачи по номерам слов | — |
| `visual-concept-agent` | Что показать зрителю: объекты, рендерер, приближения; поле `media` — рекомендация плиток с настоящим логотипом или портретом для компаний и людей, названных в тексте (subject дословно, logo/person, глава, зачем; нет таких — `null`). Студия сама возьмёт файлы из Wikimedia Commons | — |
| `scene-builder-*` | Детальная сборка предметов из каталога | — |
| `motion-2d-director`, `three-director`, `netcode-director`, `illustrated-director`, `isometric-director` (+ `-repair`) | Постановка по измеренной речи: события на слова-якоря, плавные изменения, одна постоянная система. `isometric-director` — город «Изометрия»: маршруты по улицам (перекрёстки c/r), трафик, метки, районы, связи, карточки, ключи ортографической камеры; локальная проверка до отправки — `scripts/preview-isometric.ts --project <id> --plan answer.json` (`docs/isometric-renderer.md`) | — |
|  ↳ `illustrated-director` с `media` в CONTEXT | Настоящие логотипы и портреты: `logo-tile`/`person-tile`, label = subject из media дословно, на слове названия, рядом с предметом, о котором речь; без снимка плитку валидатор не пропустит | — |
| `keyframe-review` | 6 ключевых кадров 3×2 ДО полного рендера: композиция, safe-zone, читаемость, соответствие брифу; только правки изображения | сабагент |
| `quality-<hash>-model-N` | Ревью кадров итогового MP4 (контактные листы с таймкодами) | сабагент |
| `part-N-agent`, `part-N-repair` | Разбор фрагмента Reels по кадрам | сабагент, параллельно |
| `production-summary-agent`, `reference-set-agent`, `analysis-agent` | Сводка разбора / каталог приёмов / разбор ролика автора | — |
| `style-analysis/<время>` | Профиль стиля по референсам | — |

Общие правила ответа:
- Только JSON по `schema.json`; необязательные поля — `null`.
- Экранный текст — из проверенного сценария. Логотипы и фото не рисуются от руки: настоящие — только плитки `logo-tile`/`person-tile` из снимков `media` проекта (визуальная концепция рекомендует их полем `media`, студия берёт файлы из Wikimedia Commons с лицензией).
- Никакой объект/подпись/состояние не появляется и не исчезает за один кадр (`video-design/MOTION-RULES.md`).
- Если студия вернула задание с «Исправь контракт…» — это ошибка валидатора по прошлому ответу: исправь именно её.
