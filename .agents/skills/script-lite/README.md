# Script Lite

### A free Claude Code skill by [@tenfoldmarc](https://www.instagram.com/tenfoldmarc)

Give it a topic, get 10 hooks and a ready-to-record video script that sounds like a real person talking, not AI. One-time voice paste, no scraping, no accounts, no setup.

This is the **free** version. The full `/script` (auto-analyzes your real posted videos to learn your exact voice, scrapes competitors for what's working right now, builds a hooks database that grows weekly, and runs hands-free) is part of the Go Viral System inside [AI Builders](https://skool.com/ten-fold).

---

## What it does

1. One-time setup: you paste 2-3 things you've actually written or said. It builds a quick voice profile.
2. You give it a topic.
3. It generates 10 hook options across different proven angles and recommends its top 3.
4. You pick one. It writes the full script (hook, on-screen visual, body, CTA, caption) in your voice.
5. It runs a De-AI checklist so nothing sounds robotic.
